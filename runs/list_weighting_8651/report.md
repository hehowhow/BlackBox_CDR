# LIST列表加权：两种方案与完整跨域对照

## 主要结论

**建议保留“普通均值＋LIST修正”为当前主版本；两种新加权暂不替换默认排名加权。** 第一项在两个测试比例都明确改善原LIST，第三项没有一致的进一步收益。

1. **第一项优化有效。** 均值修正版在20%/80%档的平均MAE、RMSE均优于普通均值及原LIST；真实列表也优于打乱列表，两项指标的配对区间均小于0。三个真实列表种子都选择非零修正，不是退回均值得到的表面改善。
2. **频次降权只有局部小增益。** 80%档RMSE从1.089396降至1.089006，降低0.000389（约0.036%）；条件于当前拟合模型的区间为[-0.000652,-0.000131]。80%档三个种子中两个改善、一个变差，因此也不能将这个小增益视为训练随机性下的稳定保证。但20%档RMSE从1.056126升至1.058466，明确变差。20%档MAE虽略低，差异区间跨0。不能把它认定为更好的通用版本。
3. **目标相关加权没有超过基础修正版。** 20%档RMSE增加0.000667，区间跨0；80%档增加0.001483，区间完全大于0。20%档MAE也明显变差。该结论限于本次余弦简化设计，不是否定DIN原方法或所有注意力聚合。
4. **加权后的模型仍能利用真实源列表。** 两版在两档均优于各自打乱对照和普通均值；但这只能说明仍有源增量，不能证明新加权优于已有排名池化。
5. **跨域基线必须区分骨干。** MF版EMCDR/PFCDR明显较弱；DNN版更接近均值和LIST。20%档最低平均RMSE为基础均值修正版，80%档为频次降权版，但80%档最低平均MAE属于EMCDR-DNN。不能声称某个方法在全部指标上都第一。

这里最直接的新证据是：学生只读黑盒返回的Top100 ID和排名，真实列表仍能超过均值与错配列表。结论适用于当前Music→Movie去重任务和固定划分，不自动推广到全部数据集。

两轮均使用Slurm两卡：8650耗时32分04秒，8651耗时8分40秒，均COMPLETED、退出码0；训练/反演、模型恢复、数据与代码哈希及独立审核均PASS。

## 可能的解释与边界

本轮支持“先处理好稳定的物品评分水平，再学习适度个性化修正”。但均值替换、零初始化和验证选修正强度同时改变，不能把收益精确归因到其中一个组件。
频繁返回的物品未必没有个性化信息，简单降低其权重可能也损失有效信号；目标相关加权也可能在有限重叠监督下增加学习难度。这些都是解释假设，本轮没有逐一识别成因。
独立列表统计显示，80%档中测试列表约0.38%–0.43%的返回ID未在训练列表出现；频次降权将其平均权重质量从约0.29%–0.34%提高到约1.86%–2.00%。这确认了c=0的潜在影响，但不能据此断言它导致所有性能变化，尤其该档仍有小幅改善。详见list_frequency_diagnostics.json。
基于本轮结果，下一步更值得把基础均值修正版扩展到其他方向或新划分，而不是继续扩大这两个加权方案的网格。这是建议，本轮没有额外扩展任务。
此处所有比较均复用相同历史测试划分；第一项与两种加权的设计在相应测试评价前冻结，但历史测试此前已被探索，不能称为全新盲测。PFCDR未做K/LR搜索，且采用去重数据、独立验证和重训，不是作者十次运行的精确复现。

## 方案与文献来源

A：频次降权。设排名权重q_r=1/log2(r+1)，c_j为当前训练重叠用户的Top100中物品j出现次数，则w_ur∝q_r/sqrt(1+c_j)，每个用户内归一化。内层选模仅用inner_train列表统计；最终重训重新用outer_train列表统计。验证与测试用户不参与频次估计。
该设计借鉴[LightGCN，SIGIR2020](https://hexiangnan.github.io/papers/sigir20-LightGCN.pdf)的度归一化原则。这里没有图传播，统计的是API返回频次，既不是真实源评分流行度，也不是曝光倾向概率；不声称去除了因果偏差。c=0使用加1平滑以保证有限权重，可能给训练未出现的返回ID较大权重，需要由验证结果检验。
B：目标相关加权。w_uir=softmax(log(q_r)+cos(e_source_item,v_target_item))，温度固定为1。不同目标物品获得不同的源列表表示。源/目标向量均是学生自己的参数，未读取教师权重；没有增加可训练参数。
该设计借鉴[DIN，KDD2018](https://arxiv.org/pdf/1706.06978)按目标聚合兴趣的思想，但使用归一化余弦权重，而不是DIN的MLP局部激活和非归一化权重，属于自设计简化方案，不是DIN复现。
两个公式在查看8650测试结果之前固定；不搜索加权超参数、K或学习率。两版均运行真实与打乱列表，对照使用与rank残差相同的初始参数及错配列表。
各模型仍先在相同内层验证集选择epoch0..10及lambda=0/0.25/0.5/0.75/1，再以相同初始化重训全外层训练数据。全部新模型冻结后统一评价。历史测试已使用，本轮为探索；差异区间条件于当前模型及划分，未校正多重比较。
