# DNN 源列表：其他数据集复核结论

已完成 Movie→Book 和清洗后的 Movie→Music 两个任务。
每个任务三组配对种子，MF/DNN 源模型及各自 LIST 学生全部重新训练。
DNN 列表在全部六组配对种子上均降低了相对 MF 列表的测试 MAE 和 RMSE。
这一改善在另外两个任务上重现，但两者的 RMSE 仍未达到平滑物品均值。

## 测试结果

LIST 目标评分固定为原内积。均值 ± 样本标准差来自三个完整训练流程，不是预测集成。

| 任务 | 方法 | MAE ↓ | RMSE ↓ |
|---|---|---:|---:|
| Movie→Book | 物品均值 | 0.794258 | 1.034055 |
| Movie→Book | 平滑物品均值（5） | 0.795510 | 1.019479 |
| Movie→Book | LIST，源 MF | 0.800825 ± 0.000936 | 1.031850 ± 0.000693 |
| Movie→Book | LIST，源 DNN | 0.793978 ± 0.000223 | 1.023594 ± 0.002341 |
| Movie→Music，清洗后 | 物品均值 | 0.747246 | 1.011406 |
| Movie→Music，清洗后 | 平滑物品均值（5） | 0.760533 | 0.996649 |
| Movie→Music，清洗后 | LIST，源 MF | 0.764906 ± 0.001507 | 1.015270 ± 0.002097 |
| Movie→Music，清洗后 | LIST，源 DNN | 0.751473 ± 0.002812 | 1.008283 ± 0.002324 |

物品中位数另作参照：Movie→Book 的 MAE/RMSE 为 0.725972/1.136963，
Movie→Music 为 0.671480/1.119439。DNN LIST 仍未超过中位数的 MAE，
但 RMSE 明显低于中位数。完整数值保存在 summary.json。

## 是否超过 MF 列表

是，在本轮两项任务、全部六组配对种子上均成立。

| 任务 | MAE 相对降低 | RMSE 相对降低 | ΔMAE 的 95% 用户簇区间 | ΔRMSE 的 95% 用户簇区间 |
|---|---:|---:|---|---|
| Movie→Book | 0.86% | 0.80% | [-0.008080, -0.005652] | [-0.009587, -0.006904] |
| Movie→Music，清洗后 | 1.76% | 0.69% | [-0.018419, -0.008502] | [-0.013678, -0.000164] |

差值为“DNN 列表 LIST 减去 MF 列表 LIST”，负数有利于 DNN。
采用 2000 次按用户成簇的配对 bootstrap，每次分别计算三个种子的指标后取算术平均。
区间条件于已经拟合的三组源模型/学生，不是源模型与学生随机性的全因子分析，
也不包含数据划分变化；没有多重比较校正。尤其音乐任务 RMSE 区间上界接近零，
应避免据此作普遍性结论。

## 是否超过均值

**Movie→Book：普通均值基本被追上，RMSE 有改善；平滑均值的 RMSE 仍更好。**

DNN LIST 的 RMSE 比普通均值低 0.010460，区间 [-0.013833, -0.007143]。
MAE 只低 0.000280，区间 [-0.003038, +0.002621]，这一小差异不足以支持明确的 MAE 优势。
与平滑均值比较，MAE 数值低 0.001532，但区间也跨零；
RMSE 则高 0.004115，区间 [+0.001761, +0.006380]。

**Movie→Music：尚不能说超过普通均值；对平滑均值存在指标取舍。**

DNN LIST 比普通均值的 MAE 高 0.004228、RMSE 低 0.003123，
两个差值的用户簇区间都跨零，不能把小幅 RMSE 差异当作明确优势。
相比平滑均值，DNN 的 MAE 低 0.009059，区间 [-0.015031, -0.003395]；
RMSE 却高 0.011635，区间 [+0.003976, +0.019202]。

因此，当前结论是“DNN 源列表相对 MF 源列表有一致改善”，
而不是“DNN 源列表已经在所有数据集、所有指标上战胜均值”。

## 与此前 Book→Movie 结果的关系

此前 Book→Movie 的 DNN 源列表 + 原内积 LIST 为 MAE=0.812435、RMSE=1.067772，
优于该任务的普通均值和平滑均值；那次只跑了一个源/学生种子。
本轮补上另外两个任务，每个任务三个完整流程种子，改善方向一致但幅度和基线胜负不同。

源模型中的 DNN 仍指作者代码的用户仿射变换评分，并不是另外加入深层网络。
本轮证据说明这些训练得到的 DNN 列表更适合当前 LIST 使用；
不能仅凭模型名称断言其所有源域排序指标都更好。
没有新增打乱列表或个性化信息消融，不能把本轮全部增益进一步归因到某一种列表信息。

## 数据与训练规则

| 项目 | Movie→Book | Movie→Music，清洗后 |
|---|---:|---:|
| 源域评分条数 | 1697533 | 1662200 |
| 目标训练评分条数 | 8401231 | 909144 |
| 目标验证评分条数 | 250826 | 90629 |
| 目标测试评分条数 | 245984 | 97819 |
| 重叠训练用户 | 22432 | 10724 |
| 重叠验证用户 | 7478 | 3575 |
| 重叠测试用户 | 7478 | 3575 |
| 每份 Top-100 的用户数 | 37388 | 17874 |
| 测试中训练未见目标物品评分条数 | 7 | 12 |

- 复用已有固定 60/20/20 用户划分和训练集均值统计，目标独有用户保留在训练中。
- Movie→Music 沿用清洗结果：从电影源域删除 2441 个共享物品、35333 条评分；
  复核源目标原始物品 ID 交集为零，删除列表中的物品也未重新进入源目录。
  本轮没有重新做 5-core 或改变目标音乐域。
- 源 MF/DNN 均维度 10、10 epoch、Adam lr=0.01、weight decay=0、batch=512；
  配对源模型初始用户/物品向量相同，DNN 附加层按既定默认规则初始化。
- Top-100 使用完整源目录，不排除已交互源物品、不裁剪评分；
  学生只读物品 ID，不读取返回分数、源模型权重或源交互。
- 学生保留原 LIST：排名池化、32→64→32 ReLU 编码器、dropout 0.1、
  目标物品内积、训练全局均值和物品偏置。
  每组 MF/DNN 使用同一初始学生 checkpoint 和批次顺序。
- LIST 均 10 epoch、Adam lr=0.001、weight decay=1e-5、batch=2048；
  各自按验证 RMSE 选择 epoch 1–10。无列表用户只走均值和物品偏置，
  未见目标物品按已有协议回退平滑均值。
- 全部 12 组源/学生流程冻结并完成恢复核验后统一读取测试标签。
  历史测试集已经用于之前实验，仍是探索性复核；没有时间过滤或调参。
