# LIST 分段聚合实验

## 本轮结果与结论

作业 **8703** 已完成：两张 GPU，Slurm 耗时 **7 分 57 秒**，退出码 0。24 个最终模型以及独立审计全部 PASS。
**连续分段保留了有用的跨域信息，但没有整体超过现有满意版 LIST。** β=20% 的 MAE、RMSE 都略差；β=80% 的 MAE 略好，RMSE 接近但均值略差。因此暂不替换现有主版本。

下表是三个种子各自指标的平均值，越低越好；不是模型集成结果。完整标准差、逐种子指标、EMCDR/PFCDR 等旧对照见实验目录的 report.md 和 CSV。

| 方法 | β=20% MAE | β=20% RMSE | β=80% MAE | β=80% RMSE |
| --- | ---: | ---: | ---: | ---: |
| 普通物品均值 | 0.828612 | 1.074618 | 0.840744 | 1.097641 |
| 现有满意版 LIST：全局聚合+均值残差 | 0.808497 | 1.056126 | 0.833717 | 1.089396 |
| 本轮：连续排名分段 | 0.810930 | 1.058031 | 0.832636 | 1.089779 |
| 同参数量对照：固定随机分组 | 0.811006 | 1.059973 | 0.834095 | 1.091244 |
| 连续分段，但错配用户源列表 | 0.827506 | 1.073792 | 0.840389 | 1.097504 |

相对现有满意版，分段版的变化如下；正数表示变差：

| β | ΔMAE [95%区间] | ΔRMSE [95%区间] |
| --- | --- | --- |
| 20% | +0.002433 [+0.001089, +0.003754] | +0.001905 [+0.000503, +0.003321] |
| 80% | -0.001081 [-0.001470, -0.000694] | +0.000383 [-0.000055, +0.000823] |

连续分段的真实列表在两种β下均优于普通均值和自身错配列表，相关 MAE、RMSE 差值区间均在零以下。这继续支持模型确实利用了用户对应的源信息。
连续分段的平均 RMSE 在两种β下均好于随机分组；但β=20%的差值区间跨零，β=80%才有较清晰的优势。因此可说排名分组方式值得关注，不能说本轮已证明连续分段普遍有效。
可能原因：全局聚合已经提供了较强的降噪效果，而固定切段和各段单独归一化改变了输入尺度及信息分配，也增加了拟合自由度。当前对照无法确定是哪一因素造成退步，不能直接归因于过拟合。
若继续尝试，建议保留已有效的全局聚合分支，再让分段分支只学习额外的小修正，从零修正初始化；沿用相同验证选择规则。这样可检验分段信息能否作为补充发挥作用，而不必完全替换全局表示。该方向尚未运行。

本轮在此前按两域评分总量比较最小的 Music→Movie 任务上进行。使用去重后的数据：从 Music 源域删除与 Movie 重复的物品，保留 17,904 个重叠用户。数据、源域 DNN Top100 和旧方法预测分别沿用 8638、8650 的冻结文件。

## 问题和改动

旧版满意模型（rank residual LIST）先把 Top100 压成一个 32 维向量，再用 32→64→32 的 MLP 编码。最后与目标电影的向量做点积，得到对普通物品均值的修正。

本轮预先固定三个排名段：第 1–10 名、第 11–30 名、第 31–100 名。各段分别汇总成一个 32 维向量，拼成 96 维后用 96→64→32 的 MLP 编码。后续评分仍是：

`预测评分 = 训练集中的目标物品普通均值 + λ × 用户表示与目标物品向量的点积`

每段内继续采用 `1/log2(绝对排名+1)` 的权重，并在该段内归一化。后两段不会把自己的起点重新当作第 1 名。这让模型能分别使用列表前、中、后部的信息，但不保证这些段分别代表某种兴趣，也不是逐条目与目标物品交互的方案。

## 对照和公平性

| 项目 | 本轮设置 |
| --- | --- |
| 连续分段 | 1–10、11–30、31–100；不搜索边界 |
| 同参数量对照 | 用固定随机种子 20260924 打乱 100 个排名位置，再划分为 10、20、70 个位置的三组；各用户使用相同分组 |
| 列表错配对照 | 各版分别在内层训练、验证、测试用户组内错配列表；错配后重新训练，使用与 8650 相同的用户置换 |
| 测试冷用户比例 β | 20%、80%；用户划分沿用旧实验 |
| 模型种子 | 2020、2021、2022 |
| 可访问源信息 | 固定 DNN Top100 的物品 ID 与排名 |
| 向量维度 / 隐藏层 | 32 / 64 |
| Dropout | 0.1 |
| 优化器 | Adam，lr=0.001，weight decay=0.00001 |
| Batch size / 最大训练轮数 | 2048 / 10 |
| 验证选择 | 用相同内层冷用户验证集的 RMSE 联合选择 epoch 0–10 和 λ∈{0,0.25,0.5,0.75,1} |
| 最终训练 | 从原初始化开始，在全外层训练集重训所选轮数；λ固定 |
| 评价 | 两版×两种β×三个种子×真实/错配，共24个最终模型全部冻结后统一评价 |
| Slurm | 作业 8703，两张 GPU，各运行一个新版本 |

分段版比旧版增加 4,096 个可训练参数，全部来自 MLP 第一层增加的输入连接。两个新版本的所有初始参数完全一致；它们与旧模型共同使用的其他参数，初始化逐字节一致。批次顺序、Dropout 随机种子和选择规则也保持一致。模型维度发生变化，因此不能声称分段版与旧版参数量完全相同。

随机分组对照用于检查连续排名区间是否比任意三组更有帮助。它控制了参数量和多组结构，但只使用一个固定随机划分；结果仍不能单独分离组内归一化、输入尺度和排名结构的全部作用。

GPU 自检核对了分段池化与显式加权求和一致、权重归一化、全局池化可由分段池化重构、初始输出等于普通均值、三段均能获得梯度、无源列表用户回退、参数量及初始化。训练阶段启用文件访问检查，禁止打开测试标签和源教师权重、评分。
