# 固定源 MF，比较 LIST 目标评分部分

已完成 Slurm 8600：两张 GPU、15 次训练，耗时 2 分 18 秒，全部核验 PASS。
结论见 [实验报告](../runs/list_target_heads_8600/conclusions.md) 和
[三种子汇总](../runs/list_target_heads_8600/comparison.csv)。
原内积验证集表现最好，测试均值 MAE=0.855467、RMSE=1.099332；
GMF 接近内积，DNN 略差，两个非线性评分方式也没有改善。
五种方法均未超过普通物品均值或平滑均值。

任务仍为 Book→Movie。固定 `runs/list_source_backbones_8596/queries/MF/topk_ids.npz`，
不重训源模型，不使用其他模型的排序或返回分数。

比较五种目标评分方式，均加相同的训练均值和物品偏置：

| 名称 | 交互项 | 初始化 |
|---|---|---|
| DOT | 用户与物品向量内积 | 原 LIST |
| GMF | 对逐维乘积加权求和 | 权重全 1 |
| DNN | 用户向量仿射变换后与物品向量内积 | 单位矩阵、零偏置 |
| MLP | 拼接用户和物品向量，64→64→32→1，两层 ReLU | 默认随机初始化 |
| DOT_MLP | 内积加上述 MLP 残差 | MLP 最后一层为零 |

DNN 对应作者式线性变换，并非深层非线性模型。DOT_MLP 是本轮自定义混合评分，
不冒充官方 NeuMF。GMF、DNN 和 DOT_MLP 从与内积相同的函数开始，纯 MLP 的初始函数不同。
不声称不同结构完全等价的初始化或相同参数量；参数数目保存在结果中。

共享排名池化、32→64→32 的 LIST 编码器、dropout 0.1、目标物品维度 32。
编码器结构保持一致但参数正常参与各自训练，并不是冻结编码器权重。
复用上轮词表，仅为保留完全一致的 ID 编码和 seed-2020 初始化；没有读取 GMF/DNN 的列表。
所有无源列表的目标独有用户都只走均值加物品偏置，避免头部偏置改变其行为。

每种头部跑学生种子 2020/2021/2022，共 15 次。每个种子内公共参数、训练批次、
dropout 随机序列对齐；seed 2020 复用上轮初始 checkpoint。
数据沿用相同 60/20/20 用户划分，均值基线不变。训练 10 epoch、Adam lr=0.001、
weight decay=1e-5、batch=2048；各自按验证 RMSE 选择 epoch 1–10。
方法按三种子平均验证 RMSE 选择，结果在统一读取测试标签之前冻结。
不搜索学习率、K 或 epoch 预算；未见目标物品统一回退既有平滑均值。

自检各评分公式和输入梯度、无列表用户梯度；核对所有模型恢复预测及验证最优值，
并回放核验上一轮 seed-2020 MF-list 内积模型结果。
报告每种子指标、均值/样本标准差、按用户簇配对 bootstrap 区间。
区间对每个种子分别计算 MAE/RMSE 后取均值，匹配报告口径，不是预测集成。

只固定一个源 MF 和一个数据划分；三种子仅检验学生随机性，不代表源模型/数据集稳定性。
历史测试集已用于之前探索，采用随机用户切分，没有时间过滤或多重检验校正。

入口：`sbatch scripts/slurm_list_target_heads.sh`。Slurm 分配两张 GPU，8 CPU、32G 内存，
两路顺序运行 15 次训练；遵守此前已知的每用户两卡限制，不手动占用其他显卡。
