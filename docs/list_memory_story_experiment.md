# LIST 组合记忆实验：Engram 启发的两种版本

日期：2026-09-24。Slurm 作业 **8760**，1 张 GPU，运行 **12 分 48 秒**，状态 COMPLETED / ExitCode 0:0。共完成 12 个模型：2 个版本 × 2 档冷用户比例 × 3 个种子。所有训练和独立审计均通过。

**本轮结果：组合记忆没有带来一致改进。** Top20 在 β80 的三种子平均 RMSE 只降低 0.000168，而且仅一个种子的 RMSE 改善；β20 则三个种子都变差。Top50 在两档平均 RMSE 都略差于原版。两个新版本仍优于普通均值，但这不足以说明它们优于当前 LIST。

这里的“原版”是已经归档的 `list-residual-v1` 全局排名池化、普通物品均值残差版本，参照运行 `small_task_comparison_8650/residual_real`；不是更早没有固定均值残差的旧 LIST。

**只改了什么。** 原 Top100 列表和原排名加权池化保持不变；另外把一个用户前 20 或前 50 个返回物品的无序两两组合拿出来查表。命中的组合各有一个 32 维可学习向量，对这些向量取普通平均，得到组合表示 g。把 g 加到原全局表示 h 上，再经过同一个原 MLP 和目标物品点积评分头：

\[g_u=\frac{1}{|\mathcal P_u|}\sum_{p\in\mathcal P_u}M[p],\qquad \hat y_{ui}=\mu_i^{\mathrm{train}}+\lambda\langle\mathrm{MLP}(h_u+g_u),v_i\rangle.\]

没有匹配组合时 g=0。无源列表时修正仍为零；训练未见目标物品仍回退到训练全局均值。推荐排名不是行为时间顺序，所以这里用的是无序共现对，不称作行为转移或语言 n-gram。

两个版本分别枚举 Top20 的最多 190 对、Top50 的最多 1,225 对。组合至少要被当前阶段的 3 个不同训练用户支持；超过容量时，按支持用户数从高到低保留 8,192 对，平局按组合 ID 排序。字典只根据训练用户的源列表建表，不使用目标评分值做组合筛选。

每阶段重新建字典：选模只用 inner_train 用户；最终重训用全部 outer_train 用户。验证/测试用户从不参与该阶段字典的支持计数。源端仍是原冻结 DNN Top100，仅 ID 和排名；没有读取源分数、教师向量或源历史，也没有新增源查询。

这是受 Engram 启发的简单组合查表原型，不是完整 Engram 的复现。它增加了 8,193×32=**262,176** 个存储参数（包含一个始终为零的 padding 向量），相对各随机种子的原模型增加约 13.5%–13.9%。MLP 仍为 32→64→32，没有增加注意力、聚类、IB、门控或额外评分头。本轮未加同参数量 MLP 对照，因此即使出现收益，也不能单独归因为组合记忆机制。

**保持一致的条件。** 数据划分、源 Top100、普通未平滑物品均值、dim32、hidden64、dropout0.1、Adam lr0.001、weight decay 1e-5、batch2048 都与原版一致。各模型最多训练10轮，以同一冷用户验证集 RMSE 在 epoch0…10 与 λ∈{0,0.25,0.5,0.75,1} 中选择，然后从初始参数在外层训练数据重训。

原模型的全部共享初始参数已逐项哈希匹配；两种组合版本的全部初始参数也相同。每次最终重训都重新初始化，并重建相应训练用户字典。新增记忆向量虽然是随机初始值，但原编码器末层保持全零，所以初始评分严格等于普通均值。测试标签只在全部 12 个最终模型冻结以后统一打开。

组合覆盖并不缺乏：各版本和划分的验证用户命中率为 99.895%–100%。Top20 验证用户平均命中约 105–120 对，Top50 约 362–429 对。这里仅记录覆盖，并未设置覆盖门槛阻止训练；高命中率本身不代表这些组合能改善预测。

这轮结果支持的直接判断是：**当前全局 LIST 仍应作为效果参照，简单增加组合记忆并没有明显提升。** 不能把负结果推广成所有 Engram/组合记忆形式都无效，也没有依据宣称这一实现提高了效率。当前测试划分已经在历史探索中多次使用，本轮是同划分上的探索性比较。
