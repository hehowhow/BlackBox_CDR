**当前结构真正限制了什么。** 模型使用
\[
h_u=\sum_r a_r e(s_r),\qquad z_u=\mathrm{MLP}(h_u),\qquad
\hat y_{ui}=b_i+\lambda z_u^\top v_i.
\]
这里 \(a_r\) 是归一化排名权重，\(b_i\) 是训练普通物品均值。它以固定方式把列表汇总成一个32维向量，再读目标物品。有限维度、数据量和正则化下，任务相关差异可能难以保留；但学习型求和表示不等于“理论上不能表示组合”，不能泛化地否定 Deep Sets 类模型。

对固定模型的完整用户×目标物品表，当前修正矩阵 \(ZV^\top\) 的秩至多32；更换分组后若仍输出32维并使用相同内积，也不会改变这个上界。这个事实只能指出一种结构约束，不能证明它正是性能瓶颈。

此外，
\[
\sum_r a_r e(s_r)^\top v_i=
\left(\sum_r a_r e(s_r)\right)^\top v_i.
\]
所以只把线性点积从池化后挪到池化前，没有得到新的聚合能力。若想借用逐条目证据汇总，必须真正加入非线性联合交互、目标条件选择或组合统计，并检验其价值。

**历史方向一：目标条件的信息瓶颈。该复合设计当前不采用，保留下面的分析供参考。**

直白地说，同一份音乐 Top100 在预测不同电影时，未必需要保留相同内容。当前模型始终先生成同一个用户向量；候选设计让目标物品参与压缩，再明确限制所传递的表示信息量。全部使用学生自己的源 ID 和目标 ID 嵌入，不引入源历史、文本或教师分数。

建议的可执行形式是：每个源条目与目标向量做小规模非线性交互 → 沿原排名权重汇总 → 输出高斯表示的均值与方差 → 采样表示预测评分修正。推理使用分布均值或固定的预测积分方式；选择规则事先固定。

令 \(L\) 是列表，\(i\) 是目标物品，\(\Delta=y-b_i\)，则考虑
\[
\min_{\phi,\theta}
\mathbb E\left[(\Delta-f_\theta(Z,i))^2\right]
+\eta\,\mathbb E\,D_{\mathrm{KL}}
\left(q_\phi(Z\mid L,i)\,\|\,p_0(Z\mid i)\right).
\]
第一项要求能预测目标评分；第二项约束输入中有多少细节进入表示。可先用固定标准高斯作为 \(p_0\)，避免过度增加模型容量；\(\eta\) 是正则强度，避免与冷用户比例β混淆。训练时修正强度仍为1，外层预测保留当前验证选择的λ。

这是条件 VIB 的适配，思想来自 [IB 原始工作](https://arxiv.org/abs/physics/0004057)和 [Deep VIB](https://arxiv.org/abs/1612.00410)。条件 KL 满足
\[
\mathbb E_{L,i} \mathrm{KL}(q(Z|L,i)\|p_0(Z|i))
= I(Z;L|i)+\mathbb E_i\mathrm{KL}(q(Z|i)\|p_0(Z|i)).
\]
因此它是条件输入信息量的上界，而不是“已经精确测量了互信息”。

这个设计与旧加权B的区别是：旧版只使用固定温度的余弦 softmax 重新分配条目权重；新版包含目标条件的联合变换、随机表示及显式信息约束。但每一个改动都可能是实际原因，必须有“相同网络去掉 KL”和“全局 VIB”的对照。

几个不能跳过的边界：

- 单纯对已有 \(h_u\) 加 KL，不能恢复进入 \(h_u\) 前已丢失的差异；它适合做低成本正则化对照。
- 残差标签并不凭空创造新的 IB 理论：给定目标物品和固定训练基底，\(I(Z;\Delta|i)=I(Z;y|i)\)。均值分解有工程和分析价值，但这种变量平移不是新定理。
- IB 不自动识别“热门噪声”，也不保证保留真实语义兴趣；热门条目也可能有用。
- KL趋近零而成绩回到均值，可能是表示塌缩，并非成功去噪。应观察信息约束强度与误差的折中。
- 不应把一条完全读取原列表的旁路保留下来，同时宣称整个模型经过了该信息瓶颈。
- 如果另做离散条目选择，稀疏门控正则不当然等于所传递条目内容的信息量上界，需要另行推导。
- 已查询Top100后学生只用其中10条，不能宣传为API只传输了10条。选条预算、表示容量与接口通信预算是不同量。

一个有说服力的结果会是：相同预测预算下，用更小表示保留同等或更好的目标增量，且在重叠监督更少、列表轻微扰动时更稳定。只提升一个历史测试数字不足以证明上述机制。

**方向二：借鉴 Engram 的组合记忆，优先记忆可重复的组合，而不是排名相邻的 n-gram。**

Engram 的可迁移启发是把重复离散模式交给专门记忆。原文的语言 token n-gram 有局部序列含义；我们的Top-K位置是推荐强弱顺序，不是时间或语法。第8与第9名相邻，不能直接解释成行为转换。这是适配必须解决的差别。[Engram 原文](https://arxiv.org/html/2601.07372v1)。

一个小规模原型可以这样做：

1. 保留所有原有单物品编码；从前20名生成无序物品对，每用户最多190对。
2. 键采用规范化的两个ID，不使用精确相邻名次作为键；排名权重可以进入后续加权。
3. 只用当前训练用户统计组合支持度。覆盖足够的组合拥有小向量，其余回退为零或组合函数；先用显式字典验证，确有规模需求再用多哈希表。
4. 组合向量和原有全局向量共同进入一个小编码器，预测同一个均值修正。不是增加另一套独立评分任务。
5. 不存用户ID对应答案；记忆参数只从目标训练监督学习。验证/测试不写入记忆，内层选择与最终重训分别建表。

它试图回答：“A、B同时出现在列表里”是否比单独处理A、B更有跨域预测价值。全局网络可能也能学到这种关系；专门记忆的假设是学习与共享更有效，不是表达上绝对不可替代。

与硬聚类的区别：硬聚类把物品分到固定类别，每个类别再求均值；组合记忆允许A同时参与(A,B)、(A,C)等多个模式，不预设单一归属。它仍可能因为组合稀疏而失败，特别是在β80%的少监督设置下。

必须先测训练支持度、验证组合命中率、每用户有效组合数量；低覆盖时不要靠扩大表硬撑。多哈希碰撞会串扰，不能把碰撞导致的“命中”当作模式泛化。单次查表近似常数成本不等于整个组合构造是O(1)，前M项两两组合是O(M²)。

必要对照是同参数量的宽MLP、FM/NFM式分解组合，以及无有效组合信息的表对照。若只有高频组合人群改善，应明确报告覆盖分层，而不是将收益描述成普遍兴趣推理。ComeIR 已在推荐中引入 Engram，因此候选贡献只能落在“纯排名列表如何构造和利用可迁移模式”上。[ComeIR](https://arxiv.org/abs/2605.11447)。

**方向三：从视觉识别借鉴二阶聚合，作为组合路线的廉价诊断。**

不把100条分成多个簇，直接把列表当成一个带权特征分布。除了均值 \(h_u\)，再加入
\[
C_u=\sum_r a_r(e(s_r)-h_u)(e(s_r)-h_u)^\top.
\]
可以只用方差对角线或少量投影上的二阶统计，限制维度。对于固定表示，均值相近但分散程度不同的列表可以据此区分。这保留的是特征分布形状，不应直接称为两个物品的精确共现次数。方法来源是成熟的二阶/双线性池化，而非新的理论发现。[CVPR 2016](https://openaccess.thecvf.com/content_cvpr_2016/html/Gao_Compact_Bilinear_Pooling_CVPR_2016_paper.html)。

另一种更直接的组合诊断是NFM式二阶交互：
\[
p_u=\tfrac12\left[
(\sum_r a_r e_r)\odot(\sum_r a_r e_r)
-\sum_r a_r^2(e_r\odot e_r)\right]
=\sum_{r<t}a_ra_t(e_r\odot e_t).
\]
它可以O(Kd)计算，避免建大组合表；与协方差形式相关但用途和解释不同，不混为一谈。[NFM](https://arxiv.org/abs/1708.05027)。

先选其中一种小原型，不同时搜索大量池化方式。若二阶特征在相同容量和正则对照下无收益，而组合支持度也低，Engram路线优先级下降；这仍不是严格否定所有显式记忆模型。

**方向四：检索历史用户的跨域证据，优先当作基线。**

借鉴TabR：用源列表相似度，从训练用户中检索邻居，再参考这些邻居对目标物品的评分残差。它能检验“参数网络是否只是没学好一个本来适合邻域迁移的问题”。从固定加权Jaccard或余弦的邻居残差开始，比直接训练复杂检索器更容易判断。[TabR](https://proceedings.iclr.cc/paper_files/paper/2024/hash/4ef594af0d9a519db8fb292452c461fa-Abstract-Conference.html)。

当前目标评分矩阵稀疏，同一电影的邻居证据可能不足，要报告覆盖。训练检索必须排除当前用户及自己的答案，内层记忆库不能含验证用户，测试记忆库只能含外层训练用户。交叉拟合比“只去掉当前一条评分、保留同用户其他目标历史”更接近目标冷用户设定。这条路线与经典邻域协同过滤接近，不能仅因叫记忆或检索增强就称为新架构。

**理论可以先解释可迁移信息与压缩损失，而不用承诺不现实的保证。**

以下是条件期望的标准恒等式在本任务中的推导，不作为原创定理。固定训练数据及训练得到的模型；随机变量 \(L,i,Y\) 取自被评价的评分分布，假设平方可积。它描述观察到的评分预测，不识别因果偏好或未观察评分。

设 \(b(i)=\mathbb E[Y|i]\)，\(m(L,i)=\mathbb E[Y|L,i]\)。则
\[
\mathbb E[(Y-b(i))^2]-\mathbb E[(Y-m(L,i))^2]
=\mathbb E[(m(L,i)-b(i))^2]\ge0.
\]
这给出“列表理论上有用”的精确目标：知道列表是否改变条件期望。右侧不是从现有有限样本结果已经估计出的oracle收益。

再令 \(H=h(L)\)，\(m_H(H,i)=\mathbb E[Y|H,i]\)。有
\[
\mathbb E[(Y-m_H(H,i))^2]-\mathbb E[(Y-m(L,i))^2]
=\mathbb E[(m(L,i)-m_H(H,i))^2].
\]
它把聚合问题表述为：表示压缩后，是否仍丢失与目标评分有关的条件均值差异。形式来自平方误差的正交分解，交叉项因条件期望性质为零。

最后，对实际的固定样本均值基底 \(\hat b(i)\) 和已训练修正 \(f(L,i)\)，令 \(\Delta=Y-\hat b(i)\)，则
\[
\mathrm{MSE}(\hat b+\lambda f)-\mathrm{MSE}(\hat b)
=\lambda^2\mathbb E[f^2]-2\lambda\mathbb E[\Delta f].
\]
如果修正与残差没有足够正相关，增大修正强度就会伤害预测。它解释为什么要验证选择λ，也解释错误列表不能仅凭更大模型产生可靠收益。验证选λ包括0不等于测试一定不退化；前两个oracle等式也不等于有限样本训练保证。

可以将论文主线写成：受限列表接口保留多少目标增量 → 哪类压缩保留这种增量 → 何种组合需要额外表示 → 在不同监督规模下怎样控制估计误差。信息瓶颈是其中一种可执行原则，Engram式记忆是另一种待验证表示手段。

| 条件满足后 | 小规模显式组合记忆，再考虑哈希扩容 | 组合覆盖足够，且优于同容量MLP、分解组合及错配对照时继续 |
| 最后确认 | 新划分与其他跨域方向；若写排序推荐则补排序指标 | 不以同一历史测试反复试验作为最终独立证据 |

模型筛选可以先单种子验证筛掉明显无效方案，再对保留方案做三种子；这种筛选并不能证明被淘汰方案普遍无效。沿用普通均值、同一DNN列表、数据去重、用户划分、主指标和λ规则；候选的调参预算应大致相同。初筛可以沿用10轮，但若训练曲线明显未收敛，失败结论须限定在该预算，不能当作方法上限。

如果拟合误差降低而验证误差升高，应先与普通dropout/weight decay对照，而不是立即增加模块。如果标量用户偏移已经解释大部分收益，论文应承认评分校准的作用，再证明其余部分的物品区分价值。如果所有新方法都不能稳定改善，也可以围绕受限接口、强基线和机制证据组织论文；不过现有架构本身的新颖性确实有限，需要同接口强基线和独立验证支撑。

后续讨论已撤回“目标条件IB优先、同批二阶、检索必须补齐”的排期。当前IB候选只在原全局池化之后引入随机瓶颈，不混入条目交互；信息采集独立探索；Engram须先有组合支持和验证覆盖依据。二阶、检索等不在当前实验队列，最新决策见[剩余优化故事线](list_remaining_optimization_tracks.md)。
