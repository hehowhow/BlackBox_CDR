每个任务覆盖论文 β=20%、50%、80% 三档冷用户测试比例，每档三个模型种子 2020/2021/2022。
测试人数按 round(β×重叠用户数) 计算，计数规则与作者一致。
对原始用户 ID 排序后用固定随机排列划分，三档测试用户嵌套，模型种子不改变划分。
不保证用户名单与作者相同。保留全部目标独有用户参与目标训练。

为让最终训练重叠用户数等于 (1−β) 对应人数，先从外层训练重叠用户中抽取20%作为内层冷用户验证。
LIST 在其余目标训练评分上训练10轮，以验证 RMSE 选 epoch；随后重新初始化并用全部外层训练评分
训练所选轮数。最终物品均值也只使用同一外层训练评分。
验证用户在最终重训时进入训练是预先规定的流程，测试用户始终不能进入目标训练。

LIST 沿用目前表现最好的 DNN 源 Top100 版本，目标评分仍是原 LIST 内积。
源模型为作者式用户仿射变换 DNN，dim10、10轮、Adam0.01、weight_decay0、batch512。
不为新任务临时改参数，因此 Music→Movie 源 batch512 与作者 config 的256不同。
LIST dim32、hidden64、dropout0.1、Adam0.001、weight_decay1e-5、batch2048。
仅使用 DNN 返回物品的 ID/排名建立词表，不再包含无关 MF/GMF 返回 ID。
源 Top100 不裁剪分数、不过滤已交互源物品，学生不能读取源评分、权重或返回分数。

源训练不依赖目标划分，每任务/种子的源模型在三个 β 间复用。
共9个源模型、27次内层选轮数训练、27次最终重训。三种子指标算术均值不是预测集成。
普通均值定义为目标训练集中该物品的平均真实评分；未见物品回退训练全局均值。
LIST 遇到目标训练未见物品也回退同一个普通均值。没有使用平滑均值。

所有27个最终模型冻结、恢复 checkpoint 并完整重放测试预测核验后，才统一打开测试标签。
独立 groupby 核查物品均值；核对数据与代码哈希、去重交集、训练测试用户互斥、原 LIST 前向和梯度。
报告 MAE、RMSE、三种子样本标准差及按测试用户重采样的配对置信区间。
区间条件于固定划分和已训练模型，未作多重比较校正。
