共享模式重构与残差注意力：seed2021 三数据集实验

本轮目的
在原ID LIST＋郎之万上，替换源列表编码器。取消上一版的物品频次统计、频次分组与组内频次加权参考。
让模型从训练用户的有序Top-K中学习共享模式，再读取逐位置重构未能解释的残差。
这是结构上的两阶段，并非先预训练一个模型、再训练另一个模型；全部模块在原训练预算内联合学习。
不声称第一阶段必然只学热度，或第二阶段必然只学冷门物品/纯个性化偏好。

输入与数据边界
沿用官方原ID消融10222的冻结DNN Top100查询，输入仅为源物品ID与排名。
不读取源评分、源模型参数、源交互历史、物品内容、SID或原ID到粗码映射。
Music→Movie仍使用去重数据；三任务为Music→Movie、Book→Movie、Book→Music。
每个任务跑β20%与β80%，仅seed2021，共6组新训练。
验证选择阶段的重构任务只使用inner_train中的重叠用户列表；最终重训阶段只使用outer train中的重叠用户列表。
重构分类器候选ID为对应训练用户列表中出现过的ID集合。这里只取集合，不统计频次、不按频次赋权。
验证/测试用户的列表只用于各自的预测，不用于辅助重构训练。

编码器的具体实现
1. 每个排名位置保留原始物品向量，并配有可训练排名编码。
2. 4个跨用户共享的可训练查询，通过注意力读取物品向量与排名编码，压缩成4个用户条件的共享模式向量。
   注意力logit保留原版log(q_r)先验，q_r为归一化的1/log2(r+1)。
   注意力输入做无额外参数的LayerNorm；值向量保持为原物品向量。
3. 解码器以排名编码为查询，只读取4个共享模式，重构各个位置的物品向量。
   解码器没有直接读取当前物品ID/物品向量的旁路。
4. 每个位置的残差=原物品向量－该位置的重构向量。
5. 对重构向量做带排名先验的注意力聚合，形成共享表示。
6. 由共享表示形成查询，对逐位置残差做注意力聚合；残差注意力也保留排名编码和原版log(q_r)先验。
7. 共享表示、残差表示分别经线性映射后相加，输出32维条件表示，接回原MLP、均值/方差头与条件能量网络。

初始化
原有全部参数与10222对应seed2021初始化一致，没有加载训练后的基线权重。
新融合注意力查询初始化为零，两路输出映射初始化为单位阵，因此最初输出恢复原版排名加权表示。
新增模块在独立RNG上下文中初始化；遮挡随机数也使用独立generator，避免改变原推荐训练的随机数流。
coarse_vocab只用于复现10222历史初始化时的RNG消耗，不代表本轮使用粗码。

辅助重构任务
每个训练用户随机均匀遮住20/100个排名位置。
被遮住的物品在共享模式注意力中被排除，值也置零；保留原排名，避免让输入内容泄漏预测标签。
只通过其余80个物品形成共享模式，用排名查询重构被遮住的位置。
对重构向量做无参数LayerNorm，再与训练ID集合对应的物品向量计算全量softmax分类分数。
分类器与原物品向量表共享权重，不增加另一张ID表。
这是对已发布推荐列表的ID预测，不是恢复源域真实交互历史；其他ID作为分类候选不等于负偏好标签。
辅助损失=被遮挡位置上的平均交叉熵/log(训练ID集合大小)。
总训练目标=原有郎之万模型的推荐训练目标+0.1×辅助损失。
4个模式、20%遮挡、0.1系数均在测试前固定，没有搜索。

保持一致的设置
DNN Top100，原ID输入；潜变量32维、MLP隐藏宽度64、原dropout0.1。
64个完整用户为一批；10轮选择预算；Adam学习率0.001，weight decay 1e-5。
初始潜变量标准差0.5，标准差范围0.05至1，评分噪声方差1。
训练/预测郎之万均20步，步长均0.25；训练32条链，预测128条链；能量界5。
目标物品普通训练均值加个性化评分修正；λ候选仍为0、0.25、0.5、0.75、1。
只在验证集按RMSE选择轮次与λ，再以相同初始化在完整训练集重训所选轮次。
λ=0表示最终预测等于普通物品均值；结果表必须显式记录这一选择。

相较原版的实际变化与比较范围
增加11584个可训练参数，且新增辅助重构目标；不能称为参数量完全相同或训练目标完全相同。
沿用原训练循环、优化器更新次数、数据划分、初始旧参数、评分结构和采样器；原采样实现未修改。
对照复用10222原ID LIST＋郎之万和20261016上一版频次组残差模型的冻结预测，并核验哈希。
额外列出同一测试集的普通物品均值。没有增加普通两层注意力实验，也没有调参。
单种子结果仅回答这一次固定改动的推荐指标变化，不代表多种子稳定提升或已证明消除流行度影响。
