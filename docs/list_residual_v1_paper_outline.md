# LIST：仅利用黑盒源推荐列表的跨域冷用户评分预测

写作日期：2026-09-25。本文对应已归档的 `list-residual-v1`：commit `cf32acea43ee6065f40f3b9767cf2fd0db61b935`，tag `list-residual-v1-20260924`。依据为 [版本快照](current_list_version.md)、[固定参数](../configs/list_residual_v1.json) 和 [主图](figures/list_residual_v1_workflow_v2.png)。正文按图中(b)、(c)、(d)、(a)的实际模块展开。

建议英文标题：**LIST: Cross-Domain Cold-Start Rating Prediction from Black-Box Recommendation Lists**。

## 1. 核心主张与研究问题

**核心主张：源推荐服务输出的列表可以作为跨域迁移的输入；目标模型用目标评分监督学习如何解读这些ID与名次，并预测用户相对目标物品平均评分的偏离。**

例如，一个用户在音乐平台已有记录，但刚进入电影平台，没有可用于训练的电影评分。音乐平台可以提供给这个用户的推荐列表，电影平台只能看到音乐物品ID与排序，看不到源历史、真实评分、预测分数或内部模型向量。LIST研究能否利用这份列表，更准确地预测该用户对电影的评分。

核心研究问题可以写成：

> 当源端只返回Top-K物品ID和排名时，这种有限的可观察输出是否仍然包含目标域可利用的用户相关信息？如何把这些信息转化为超过目标物品普通均值的评分预测增量？

当前设定如下：

| 要素 | 明确定义 |
| --- | --- |
| 源端输入/输出 | 已知用户u；输出其源域Top100物品ID及顺序 |
| 学生不可访问 | 源历史、源评分、返回分数、教师参数/向量/梯度、物品文本 |
| 训练桥梁 | 已知跨域用户对应，重叠训练用户具有源列表和目标训练评分 |
| 测试任务 | 目标冷用户评分预测：测试用户没有目标训练历史，但有自己的源列表 |
| 物品关系 | 源/目标物品目录去重，不依赖共享物品 |
| 输出 | 用户u对目标物品i的预测评分；当前证据使用MAE/RMSE |

图中的Top-K是**源输入列表**，不是模型最终输出的目标推荐榜单。列表反映源服务的判断，也不能直接等同于用户真实消费过或喜欢过的全部物品。

## 2. 现有方法的gap与本文切入点

### 2.1 接口能力的差距

EMCDR先学习两域表示，再用重叠实体学习跨域映射；使用源域潜向量是其工作流的一部分。只获得ID/排名的目标学生无法直接取得这类输入。[EMCDR原论文](https://www.ijcai.org/proceedings/2017/0343.pdf)

PFCDR通过源端模型反演生成原型；作者实现包含对可优化输入反向传播的反演阶段和原型导出。这需要源服务额外提供相应能力，普通Top-K返回本身不足以原样执行该流程。[PFCDR官方代码](https://github.com/walcheng/PFCDR)

因此，本文针对的gap是：**在源服务只提供列表、不能额外开放模型内部表示或原型接口时，如何进行目标冷用户评分预测？** 这是一组明确的访问条件，不能概括成“所有现有CDR都需要共享原始数据”。

### 2.2 从有限输出构造可迁移表示

只有物品ID和顺序时，没有教师向量可以直接对齐，没有源预测分数可以做分值拟合，两域物品也不需要一一对应。本文让目标模型自行学习源ID的表示，并通过重叠用户的目标评分学习源列表与目标评分之间的关系。

这里的迁移桥梁是“同一个训练用户的源列表与目标评分”，不是共享物品，也不是源/目标物品之间预先指定的语义对应。

### 2.3 明确区分目标域基底与跨域增量

普通物品均值已经能解释一部分目标评分。比较跨域模型时，需要问的是：源信息是否在这个基底上提供了额外价值，以及价值是否依赖列表确实属于该用户。

这是本文强调的建模和评价问题。偏置建模、物品聚合和个性化内积已有经典先例；例如FISM采用历史反馈物品的因子聚合与目标物品交互。因此不能将“求和聚合”或“基底加个性化项”单独作为首次提出的技术。[FISM原论文](https://chbrown.github.io/kdd-2013-usb/kdd/p659.pdf)

## 3. LIST方法：逐模块对应主图

### 3.1 图(b)：Black-box list acquisition

冻结的源DNN接收用户u，返回：

\[
L_u=(s_1,s_2,\ldots,s_K),\qquad K=100.
\]

其中s_r是源列表第r名的物品ID。只有ID与名次跨过图中的访问边界，教师向量不进入学生模型。当前实验使用同一冻结源模型导出的固定列表快照。

主图中的“acquisition”表示获取这份固定Top100列表。该归档版本没有按用户调整K或主动选择查询。源DNN命名沿用作者代码，其实现是用户仿射变换后与物品向量内积；当前Top100未过滤已交互源物品。

### 3.2 图(c)：Rank-weighted list encoder

**第一步，学生自己的源ID查表。** 每个s_r映射为32维向量e(s_r)。这些向量通过目标评分训练，来自学生自己的参数表。

**第二步，一次全局排名加权聚合。**

\[
q_r=\frac{1}{\log_2(r+1)},\qquad
h_u=\frac{\sum_{r=1}^{K}q_r e(s_r)}{\sum_{r=1}^{K}q_r}.
\]

越靠前的名次获得越大的固定权重；q_r不是源模型分数，也不是学出来的注意力或概率。所有条目合成一个32维向量h_u。

**第三步，转换为目标任务使用的用户表示。**

\[
z_u=\operatorname{MLP}(h_u),\qquad
\operatorname{MLP}:32\rightarrow64\rightarrow32.
\]

MLP含ReLU与dropout=0.1。z_u仍为32维。此时目标物品i尚未参与计算，同一个用户表示可以用于不同目标物品的评分。

### 3.3 图(d)：Mean + rating correction

**目标物品分支。** 目标物品i通过学生的目标ID表得到32维向量v_i。用户表示与它作内积：

\[
\delta_{ui}=z_u^\top v_i.
\]

δ_ui是待学习的评分修正，可以为正或负。

**固定均值分支。** 只用当前阶段的目标训练评分计算普通物品均值：

\[
\mu_i=\frac{1}{|R_i^{\mathrm{train}}|}
\sum_{r\in R_i^{\mathrm{train}}}r.
\]

它不平滑，不由MF预测，也不通过梯度学习；额外可训练物品偏置冻结为零。

**相加形成最终预测。**

\[
\boxed{\hat r_{ui}=\mu_i+\lambda\delta_{ui}
=\mu_i+\lambda z_u^\top v_i.}
\]

λ是对当前训练出的模型统一使用的全局标量，由验证集选择，不是逐用户/逐物品门控。例如某电影均值4.0，LIST修正−0.4，λ=0.5，则最终预测为3.8。

### 3.4 图(a)：完整工作流与训练信号

完整推断链条为：

> 用户u → 冻结源DNN → Top100 ID/排名 → 学生源ID查表 → 排名加权全局聚合 → MLP得到z_u → 与目标物品向量v_i内积 → 乘λ → 加固定普通物品均值μ_i → 预测评分。

图右下角训练框采用：

\[
\mathcal L_{\mathrm{MSE}}
=\frac{1}{|\mathcal D_{\mathrm{train}}|}
\sum_{(u,i,r_{ui})\in\mathcal D_{\mathrm{train}}}
\left(\mu_i+z_u^\top v_i-r_{ui}\right)^2,
\qquad \lambda_{\mathrm{train}}=1.
\]

目标训练评分的误差同时更新学生源ID向量、MLP和目标物品向量。训练通过这些共享参数学习：源列表中哪些模式与目标评分相对于物品均值的高低有关。源DNN和均值统计不接受这条训练梯度。

| 部分 | 是否训练 | 对应图中位置 |
| --- | --- | --- |
| 源DNN | 冻结 | (b)及(a)左侧 |
| 学生源ID向量、MLP | 由目标评分联合训练 | (c)及(a)列表编码器 |
| 学生目标物品向量 | 由目标评分联合训练 | (a)目标物品查表、(d)绿色向量 |
| 普通物品均值μ_i、排名权重q_r | 固定统计/固定公式 | (d)金色分支、(c)权重列 |
| λ | 训练和重训取1；最终预测使用验证选择值 | (a)/(d)乘法节点与训练框 |

与图配套的训练细节：

1. 编码器最后一层零初始化，因此初始δ_ui=0，预测严格从普通均值开始。
2. 内层训练使用内层训练均值；按冷用户验证RMSE选择epoch=0…10及λ∈{0,0.25,0.5,0.75,1}。
3. 选定后，从原初始化在完整外层训练集重训选定轮数，使用该训练集重新计算均值；重训损失仍取λ=1，最终预测才乘选定λ。
4. 无源列表时修正为零；目标训练未见物品时修正置零并回退训练全局均值。λ=0是可选的验证回退，不是测试不退化保证。

## 4. 目前的特色与可以写成贡献的部分

### 4.1 特色一：通过服务输出建立跨域连接

LIST把源推荐列表当成可学习的用户描述。相同源ID在不同用户列表中共享学生表示，由目标监督学习它们对另一个物品空间的预测价值。实现不需要源教师向量映射、源评分拟合或共享物品。

可以写为：**研究并实现仅基于源Top-K ID及排名的目标冷用户评分预测，将源服务可观察输出作为跨域迁移媒介。** 这是接口与任务结合的贡献表述，不作“首次使用列表迁移”的断言。

### 4.2 特色二：以强均值基底组织迁移任务

将“这个物品通常得多少分”交给固定普通均值，将“该用户可能高于或低于均值多少”交给源列表分支。零修正初始化与验证确定的全局λ使该设计具有清楚的起点和可调的修正幅度。

可以写为：**提出与受限列表接口配套的均值残差预测框架，直接学习源列表条件下的目标评分增量。** 贡献在于整体设定与可检验设计；残差、零初始化、排名加权、MLP和内积均不能单独包装成新发明。

### 4.3 特色三：通过对照检验用户对应的跨域信息

在去重数据和按用户隔离的划分上，同时比较普通均值、真实用户列表、完整重训的错配用户列表。错配对照保留结构和训练方式，但改变用户与列表的对应关系。

可以写为：**通过强基底和完整错配重训对照，提供源列表包含用户相关目标评分增量的经验证据。** 这是实验贡献，不是新的网络模块，也不自动证明增量来自具体语义兴趣或因果偏好。

论文中的三条贡献可直接组织为：

1. 明确源端仅返回ID/排名时的跨域冷用户评分预测问题及信息访问边界。
2. 构建源列表编码与固定目标均值残差相结合的简洁框架，完全通过目标训练评分学习学生表示。
3. 在去重任务上，用普通均值与完整重训的错配列表对照验证该接口的用户相关增量。

当前不宜把模型写成“具有全新理论的复杂架构”。受限接口的研究问题、方法与评价设计的对应关系，是这一版最清晰的论文主线。

## 5. 已有证据如何支撑outline

归档版本的完整主证据为Music→Movie去重版，17,904名重叠用户，β20%/80%，三个模型种子，固定用户划分。下表为逐模型指标的均值，越低越好。

| 方法 | β20 MAE | β20 RMSE | β80 MAE | β80 RMSE |
| --- | ---: | ---: | ---: | ---: |
| 普通物品均值 | 0.828612 | 1.074618 | 0.840744 | 1.097641 |
| LIST归档主版本 | 0.808497 | 1.056126 | 0.833717 | 1.089396 |
| 同结构、完整重训的错配列表 | 0.826968 | 1.073404 | 0.840470 | 1.097543 |

LIST相对普通均值的RMSE降低约1.72%和0.75%；真实列表优于错配列表，支持用户对应的列表具有额外预测价值。详细证据见 [归档结果](../runs/small_task_comparison_8650/report.md)。

该证据不等于所有数据方向、所有方法或所有指标上的最优；例如β80的EMCDR-DNN的MAE低于LIST。当前也没有Top-N排序效果、正式隐私保护保证或全新理论证明。历史测试已被用于探索，更多方向与新划分仍需单独验证。

## 7. 与主图一致的英文图注草稿

**Overview of LIST for cross-domain cold-start rating prediction.** (b) A frozen source recommender returns a Top-100 list containing only item IDs and ranks. (c) The student learns its own source-item embeddings, pools them with normalized rank weights, and maps the pooled representation to a target-task user vector through an MLP. (d) Its inner product with a target-item embedding provides a rating correction, which is scaled by a validation-selected global coefficient and added to the ordinary target-item training mean. (a) The overall framework is trained with target-domain rating supervision. During training, the correction coefficient is fixed to one; the source model and item-mean statistics remain fixed.

实现依据：[ResidualList](../scripts/small_task_comparison.py)、[学生编码器](../scripts/list_source_backbones.py)。本outline中的主方法严格为图示归档版本；之后的IB、组合记忆、分段/聚类、固定K对照和未实现的主动采集都不是该版本的组成部分。
