# 条件高斯：只调整评分噪声方差

本轮遵从“只调评分噪声方差”的要求，不调整训练强度或修正系数的搜索范围。

## 实验设置

- 三个任务：Music→Movie去重版、Book→Movie、Book→Music。
- 每个任务保留β=20%/80%，只使用随机种子2020。
- 评分噪声**方差**q∈{0.25, 0.5, 1, 2, 4}；不是标准差。
- 3任务×2档β×5方差，共30组内层选模及外层重训。
- 固定最大10轮、Adam学习率0.001、weight decay=1e-5、每批64名用户、全部用户训练评分。
- 固定向量32维、hidden64、dropout0.1、潜变量初始标准差0.3及标准差范围0.05～2。
- 固定源DNN Top100、排名加权聚合、普通目标物品均值、目标内积预测。
- λ候选仍为{0,0.25,0.5,0.75,1}，沿用验证RMSE选择epoch和λ、从头外层重训的原规则。不同q可选中不同epoch/λ，不扩大候选范围。
- 每个任务、β的最终q也仅根据验证RMSE选择；相同验证分数优先保留q=1。全部30个最终模型与q选择冻结后才进行测试评估。
- 与同一seed2020的原版LIST和旧高斯对照，不混用之前三个种子的平均指标。

## 唯一模型改动

原模型的目标评分噪声方差在公式里固定为1。本轮将这一标量真正接入高斯联合边际似然：

\[
r_u-\mu_{items(u)}\mid list_u\sim
\mathcal N(V_u m_u,\;qI+V_u\operatorname{diag}(s_u^2)V_u^T).
\]

这里q描述给定潜在目标偏好后的评分噪声，s_u²仍是根据源列表学习的潜变量方差。保留原损失尺度与按批次评分数归一化方式，不额外缩放损失。似然包含对应的log-determinant和n_u log(q)项。

q=1直接调用旧计算路径；训练、预测、选模函数复用旧文件，历史代码和结果不改写。新旧q=1的初始化、损失、梯度、预测须核验一致；其他q的似然及梯度与直接构建完整评分协方差的独立计算比较。

## 这次结果说明什么

1. **评分噪声方差确实会明显影响某些任务，但没有跨任务统一的最优值。** Music→Movie β20在五档之间的测试RMSE跨度约0.019971；Book→Movie β80约0.013638。Book→Movie β20则仅约0.001230。
2. **明确的新收益出现在Book→Movie β80。** 验证集选择q=4。相对默认q=1，MAE由0.829223降至0.824838（−0.004385），RMSE由1.094325降至1.086831（−0.007494，约−0.685%）。与原版LIST的RMSE差距由0.009045缩小到0.001552，但MAE和RMSE仍未超过原版。
3. **其余五档没有通过验证选模获得新的测试提升。** Music→Movie β20选q=4后测试RMSE增加0.001173；Book→Music β20选q=2后增加0.000257。Book→Movie β20保留q=1。Music→Movie β80和Book→Music β80的全部q均选epoch0、λ=0，最终都退回普通均值，不能解释为各q训练出的模型本身完全一样。
4. **可以报告参数敏感性，但不能从测试表里倒选参数。** 例如Book→Music β20的q=0.5在本次测试上优于默认高斯，且MAE/RMSE都低于原版LIST；验证集实际选择了q=2，因此前者只能作为扫描观察，不能当作验证选模取得的正式提升。
5. **本轮实际只新增一个可调标量。** 训练轮次上限、学习率、批次、潜变量方差范围、λ候选集合均没有改变。q进入联合高斯似然，按模型定义改变评分残差的约束；不额外改损失权重。这里只用一个随机种子，不做稳定性、显著性或机制归因。

按原验证规则选出q后，六档相对默认高斯为：**1档改善、2档略差、3档不变**。
