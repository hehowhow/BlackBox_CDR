# LAPT 论文 Outline：有限源域访问下的跨域推荐

本文围绕两个固定的挑战展开：**共享模式与用户差异混杂**、**跨域迁移歧义**。整体模型名称暂定为 **LAPT（Limited-Access Preference Transfer，有限访问下的偏好迁移）**。

## 第一段：问题背景与研究意义

推荐系统通常需要用户的历史行为来理解其兴趣，但新用户在目标平台上往往缺少足够的记录。跨域推荐希望利用用户在其他平台上的信息，改善目标平台的推荐。然而，出于用户数据保护、商业利益和平台接口限制，源平台可能不愿开放用户历史、模型参数或用户向量，只允许查询推荐结果。这引出了我们的研究问题：**当目标平台只能获得源域返回的少量物品及其排名时，如何利用这些信息改善目标域的推荐？**

## 第二段：研究问题及其内在挑战

我们研究的具体场景是：在已知跨域用户对应关系的前提下，利用重叠用户的源域推荐列表和目标域训练评分，学习跨域联系，再为缺少目标域历史、但可以查询其源域列表的用户预测评分。有限的列表中仍然包含兴趣线索，但利用这些线索面临两个挑战：

- **挑战一：共享模式与用户差异混杂。** 不同用户的列表可能包含大量共同内容，例如热门物品或普遍兴趣；与此同时，少数不同物品及其排名又可能体现用户差异。直接把整个列表压成一个向量，会将这些信息混在一起，难以充分保留有助于个性化预测的差别。
- **挑战二：跨域迁移歧义。** 一份源域列表可以对应多种合理的目标域偏好。例如，喜欢相似音乐的用户，也可能喜欢不同类型的电影。因此，即使理解了源域列表，也不能唯一确定用户在目标域中的兴趣。

前一个挑战关注**列表中的用户差异如何被保留**，后一个挑战关注**这些线索能够对应哪些目标域偏好**。

## 第三段：现有研究与主要不足

已有跨域推荐方法通常借助更丰富的信息建立跨域联系。例如，EMCDR 学习两个域的表示，再利用重叠用户建立映射；PFCDR 通过原型蒸馏和模型反演减少直接共享用户信息的需求，但仍依赖推荐列表接口之外的源域能力。因此，这些方法的访问条件与“只能获得物品及其排名”并不相同。[EMCDR 原文](https://www.ijcai.org/proceedings/2017/0343.pdf)、[PFCDR 官方仓库](https://github.com/walcheng/PFCDR)

在我们的访问条件下，原版 LIST 已经提供了一种可行方案：按排名聚合源域列表，再学习目标域评分。然而，它将列表直接合并为一个确定的用户向量，既没有为用户差异设置专门的提取过程，也没有显式描述跨域迁移歧义。**能够利用列表，不等于已经充分利用列表。**

## 第四段：提出模型、解决思路与优势

我们将整体模型暂定名为 **LAPT：Limited-Access Preference Transfer，有限访问下的偏好迁移**。

LAPT 从源域只接收物品及其排名，通过重叠用户的目标域评分学习跨域联系，并在目标物品的普通均值基础上预测个性化修正。围绕上述两个挑战，我们设计两个模块：

- **差异化偏好增强模块（DPE，Distinctive Preference Enhancement）。** 首先从多个用户的列表中学习共享模式，再关注这些模式未能解释的列表内容。模型同时保留共享信息和剩余差异，并始终利用排名信息，帮助用户之间的细微区别进入后续预测。这里的共享模式由模型学习，不依靠物品出现频次直接分配权重；剩余差异也不能预先认定为纯粹的个性化偏好。
- **条件能量驱动的偏好采样模块（CEPS，Conditional Energy-based Preference Sampling）。** 根据列表表示，学习哪些目标域偏好更加合理，再通过郎之万采样得到多个可能的用户偏好向量，并汇总它们进行预测。它让模型能够表达“给定这份列表，仍然存在多种可能”，而不是只学习一个固定的跨域映射。

两个模块分别改善**输入信息的表达**和**跨域偏好的建模**。整体优势是，在较严格的源域访问条件下，既保留列表中的用户差异，也为不确定的跨域联系提供建模空间。

## 第五段：概括文章与贡献

本文围绕有限源域访问下的跨域推荐，研究如何从推荐列表中提取用户差异，并利用这些差异建立目标域偏好模型。贡献可以概括为：

1. **现象发现：有限列表仍然包含可迁移的用户信息。** 真实用户列表与打乱用户对应关系的列表对照表明，正确对应的源域列表能够提供目标物品均值之外的预测信息，说明这种受限接口仍具有跨域利用价值。[已有对照结果](list_residual_v1_paper_outline.md)

2. **模型创新：提出 LAPT，并设计两个相互配合的模块。** DPE 针对共享模式与用户差异混杂，增强用户差异的表达；CEPS 针对跨域迁移歧义，通过条件能量建模和偏好采样支持目标域预测。

3. **实验验证：在三个跨域任务上检验方法效果。** 最初的 DNN 单种子（seed 2021）六组设置中，完整模型的 MAE、RMSE 均优于普通物品均值；相较原版 LIST＋郎之万，加入 DPE 后，MAE 在五组改善，RMSE 在两组改善。[DNN 实验结果](list_shared_reconstruction_seed2021_report.txt)。后续 MF、seed 2020 的九组设置中，相较 LIST V1＋郎之万，LAPT 的 MAE 在三组改善、两组持平，RMSE 在四组改善、两组持平；其中三组 LAPT 选择了均值回退。[MF 完整结果与限制](lapt_mf_full_seed2020.md)。因此，目前可以表述为**展示了进一步改善个性化预测的潜力，同时存在指标取舍**，尚不能写成全面、稳定领先。两轮 backbone 和种子不同，不能合并为多种子结论。
