# LIST 额外优化尝试总览：目的、最好结果与统一对照

更新日期：2026-09-27。本文汇总已经完成并保存结果的实验；数值来自本地冻结结果，未为这次整理新增训练。

**目前最值得保留的额外路线是条件高斯，但还不能说它全面替代了原版LIST。** 默认学习方差高斯在 Music→Movie β20、Book→Movie β20 的三种子平均 MAE、RMSE 上均优于原版。后续单种子调参进一步改善了结果：六档任务中，四档两项指标都优于原版，一档只改善RMSE，一档仍较差。IB、Engram启发的组合记忆、分段和多簇聚合都没有表现出覆盖两档β的一致收益。

## 1. 本文的原版、共有数据和“最好”分别指什么

### 原版LIST v1

本文的原版是已经上传GitHub、与现有工作流图一致的版本：

`冻结源DNN → Top100物品ID及排名 → 学生自己的物品向量 → 排名加权池化 → MLP → 与目标物品向量内积 → 修正目标物品普通均值`

其中，排名权重为 `q(r)=1/log2(r+1)`，在列表内归一化；表示维度32，MLP为32→64→32；最终预测为 `目标训练集物品均值 + λ × 个性化残差`。均值不平滑，模型从零残差开始学习。

原版的冻结参照是 `runs/small_task_comparison_8650` 中的 **`LIST_residual_real`**。该目录里叫 `LIST_original` 的行是更早的非物品均值残差版本；而IB目录中的 `LIST_original` 又指当前v1。本文已统一命名，避免把不同版本误作同一个对照。

### 共有数据与比较口径

| 项目 | 本文处理 |
| --- | --- |
| 所有后续优化共同做过的任务 | **Music→Movie去重版**；源Music删除2,441个跨域重复物品及34,881条评分，剩17,904名重叠用户 |
| 两档数据设置 | β20、β80；β为测试冷用户占重叠用户的比例，β80留给模型的重叠训练用户更少 |
| 固定结构实验 | 种子2020、2021、2022；报告三个模型指标的算术平均，不是平均预测的集成 |
| 后期参数扫描 | 只有种子2020；单独与原版seed2020对比，不与三种子平均混比 |
| 扩展任务 | 条件高斯、20步条件能量及相关调参还覆盖Book→Movie、Book→Music；其他结构不能填入未运行的结果 |
| 主指标 | RMSE，越低越好；同时保留MAE，不能用RMSE改善掩盖MAE退步 |
| 差值 | Δ=新版本−原版LIST v1；负数表示改善 |

**“最好”有两种含义，本文明确区分：** 有参数搜索的实验，报告当时按验证集RMSE选出的实际配置；固定的多个结构都列出结果，可以描述哪一版的测试表现较好，但不把这种事后观察冒充通过验证选模得到的最优方法。不会从两版模型分别挑最低MAE、最低RMSE拼成一行，也不会把多个单因素的最好参数拼成一个未训练过的模型。

大部分v1后续实验保持10轮预算、Adam学习率0.001、weight decay=1e-5、dropout=0.1，以及验证选择epoch 0～10、λ∈{0,0.25,0.5,0.75,1}后从头外层重训的规则。**相同的是选择规则，所选epoch和λ不一定相同。** 以下变化需要一起看：

- 高斯和能量模型为联合建模用户的多条评分，改用每批64名完整用户；原版为每批2048条交互。相同10轮并不等于相同更新次数，因此专门保留了按用户批处理的确定性点模型对照。
- 分段、聚类、IB和组合记忆有额外参数，不能声称参数量完全相同；分段和聚类另有同参数量的随机分组对照。
- Top200需要源服务返回两倍条目，收益同时包含更多信息带来的影响。
- 所有结果都来自已经多轮探索过的历史划分，单种子小幅领先不是稳定性或统计显著性的证明。

## 2. 基础版本形成过程中做过的优化

这部分解释我们为什么最终保留“DNN源列表＋内积评分＋普通均值残差”。前两类使用早期60/20/20用户划分，不能直接放进文末的β20/β80排行榜。

### 2.1 更换源模型：让返回的Top-K包含更有用的信息

目的：在相同ID和排名接口下，检查源模型生成的列表质量是否比学生端换结构更关键。我们比较MF、GMF、作者式DNN生成的Top100，保持下游旧版LIST相同。

| 早期Book→Movie，seed2020 | MAE | RMSE |
| --- | ---: | ---: |
| MF源列表 | 0.855979 | 1.098697 |
| GMF源列表 | 0.860587 | 1.099037 |
| DNN源列表 | **0.812435** | **1.067772** |

DNN列表在这轮测试的两项指标中最好，且超过该划分的普通均值（0.834888 / 1.091984）。随后扩展到另外两个**早期方向**，三种子平均如下。

| 早期任务 | MF源列表 MAE / RMSE | DNN源列表 MAE / RMSE |
| --- | --- | --- |
| Movie→Book | 0.800825 / 1.031850 | **0.793978 / 1.023594** |
| Movie→Music去重版 | 0.764906 / 1.015270 | **0.751473 / 1.008283** |

这两项的六个配对种子都改善两项指标，但当时仍未在RMSE上超过各自平滑均值。Movie→Music和Music→Movie是不同任务；前者去重后17,874名重叠用户，不混作后者的17,904名。

依据：[源模型对照](list_source_backbones.md)、[跨任务验证](list_source_transfer.md)。

### 2.2 更换目标评分头：提高源表示与目标物品的交互能力

目的：检查内积是否太简单。固定MF源列表，比较内积、GMF、作者式DNN、拼接MLP、内积＋MLP。这里作者式DNN是线性变换后内积，不能解释为深层非线性评分器。

| 早期Book→Movie，三种子平均 | MAE | RMSE |
| --- | ---: | ---: |
| DOT内积 | **0.855467** | **1.099332** |
| GMF | 0.855545 | 1.099370 |
| DNN | 0.856473 | 1.099799 |
| 拼接MLP | 0.862835 | 1.116420 |
| DOT＋MLP | 0.856037 | 1.105382 |

内积也被平均验证RMSE选中，增加评分头复杂度没有改善。这只验证了当时的MF列表及旧版LIST，不能扩大为所有DNN源列表上的非线性评分都无效。依据：[目标评分头实验](list_target_heads.md)。

### 2.3 将预测改成“物品均值＋源信息残差”

目的：让目标域已知的总体评分规律由物品均值承担，源列表只学习用户相对均值的偏好，避免重新拟合已经很强的统计基线。

早期曾用“MF源列表＋平滑均值＋可训练物品偏置＋残差”，跑20轮：Book→Movie平均RMSE为1.085331，平滑均值为1.086142，改善很小且差值区间跨零；Movie→Book、Movie→Music都由验证集选回epoch0基线。它不是当前满意版。

后来在DNN源列表上采用**普通物品均值、冻结额外物品偏置、零初始化残差**，形成目前v1。共同Music→Movie数据上，三种子平均RMSE从旧版的1.067575 / 1.124753变为v1的1.056126 / 1.089396（β20 / β80）。这一步是已经确认有效并吸收到主版本中的改动，不能再算作后续高斯或聚合模块的收益。

依据：[早期残差探索](residual_study.md)、[主版本对照](small_task_comparison.md)、[当前实现](current_list_version.md)。源历史统计、源MF用户向量等白盒诊断另见[CDR有效性分析](cdr_effectiveness_analysis.md)，它们需要超出Top-K接口的信息，不能作为同访问条件的LIST优化结果。

## 3. v1之后，每条额外优化线的目的和最好结果

以下固定结构结果均为共同Music→Movie数据上的三种子平均；调参结果明确标为seed2020。

### 3.1 频次降权：降低“所有人都返回的物品”的影响

**目的与实现：** 让列表更强调具有区分性的ID。物品在当前训练用户列表中出现次数为c，将原排名权重改成 `q(r)/sqrt(1+c)`，再归一化。c仅由训练用户统计；它是API返回频次，不能当作真实源交互流行度或曝光概率。

**最好观察：** β80得到 **0.833007 / 1.089006**，对v1的RMSE改善0.000389；β20为0.808067 / 1.058466，MAE略好、RMSE反而差0.002340。没有统一改善两档，也没有证明因果去偏。依据：[加权实验](list_weighting.md)。

### 3.2 目标相关加权：不同目标物品读取不同的源列表证据

**目的与实现：** 同一个用户面对不同目标物品时，源列表条目的重要性应该可以不同。使用 `softmax(log q(r)+cosine(源ID学生向量,目标物品向量))`，温度固定1，无新增参数。

**结果：** β20为0.814642 / 1.056793，β80为0.833733 / 1.090879；两档RMSE都没有超过v1。这是本轮简化余弦加权的结果，不等于否定全部目标条件聚合。依据：[加权实验](list_weighting.md)。

### 3.3 分段／分层聚合：先保留前、中、后段，再合并

**目的与实现：** 避免Top100一次压缩为单个向量，丢掉高排名与尾部条目的区别。固定分成1–10、11–30、31–100三段，段内各自排名加权，拼接三个32维向量，再经96→64→32 MLP输出。这里“分层”指先段内、后段间汇总，没有额外实现另一套层次注意力网络，也不是逐条目分别输出目标评分证据。

**结果：** β20为0.810930 / 1.058031；β80为0.832636 / 1.089779。β80的MAE比v1低0.001081，但两档RMSE均未改善。相对随机分组三段对照有所改善，仍不足以替换全局聚合。增加4,096个参数。后来提到的“全局分支＋分段小修正”没有实际运行，不计入实验结果。依据：[分段实验](list_segmented_experiment.md)。

### 3.4 共现聚类与簇数搜索：按可能的兴趣组合分组

**目的与实现：** 排名相邻未必代表同一兴趣，因此改用训练用户Top100中的共现，做归一化矩阵→SVD32→K-means。每簇独立聚合后拼接，仍由MLP输出一个用户向量；内层、外层分别只用各自训练用户拟合分组。

**结果：** 固定C=3得到β20的0.809601 / 1.057300、β80的0.834123 / 1.090821，均没有超过v1的RMSE。之后扫描C∈{1,2,3,4,8,16}，按三个种子的平均验证RMSE选择，两档都选 **C=1**；对应测试为 **0.808707 / 1.056031**、**0.833685 / 1.089303**。

C=1的RMSE比v1低约0.000095 / 0.000093，但已退化成单组，且训练未见ID处理不同。因此这不能作为“多兴趣聚类有效”的证据。簇数搜索仅对选中配置及控制组测试，不能声称已经知道所有C的测试排名。依据：[聚类原型](list_cluster_experiment.md)、[簇数搜索](list_cluster_count_search.md)。

### 3.5 IB：压缩可能无用的源列表信息

**目的与实现：** 尝试让表示保留对目标评分有帮助的信息，减轻对源列表偶然细节的拟合。实际做的是**64维隐藏层VIB**：训练时高斯采样，加η×KL约束；预测时用隐藏均值。瓶颈不在最终32维用户向量上。比较η=0、10⁻⁴、10⁻³；η=0也含随机结构，不等于确定性v1。

**最好观察：** 有KL的两版中，η=10⁻⁴较好：β20为 **0.809948 / 1.055626**，RMSE比v1低0.000500，三个种子的RMSE都改善，但平均MAE变差；β80为0.834127 / 1.090105，两项都差于v1。η=10⁻³两档明显退步。

无KL随机对照β20为0.809326 / 1.055998；相较这个对照，小KL仍只是局部RMSE收益。现有结果没有证明解释性、隐私保护或稳健性提高，也没有补齐与普通正则化调参的对照。依据：[IB实验](list_ib_story_experiment.md)。

### 3.6 Engram启发的组合记忆：显式记住一起出现的物品

**目的与实现：** 单个ID向量相加未必容易表示“两个物品一起出现”的模式，因此为列表前20名或前50名中的无序物品对建立记忆表。只收训练用户中至少3人支持的组合，最多8,192项，每项32维；命中向量取平均，加到原列表池化向量后再进原MLP。

**最好观察：** β20的两版中，前50名组合较好，为 **0.810955 / 1.056899**，仍差于v1；β80前20名组合较好，为 **0.833160 / 1.089227**，RMSE比v1低0.000168，但只有一个种子的RMSE改善。前20／前50指建组合的前缀，模型仍接收完整Top100，不等于采集线的Top20／Top50。

这是增加约26.2万个存储参数的组合查表原型，没有复现完整Engram，没有证实效率提升，也没有同容量MLP/FM对照。目前不能据此建立“记忆带来稳定推荐收益”的结论。依据：[组合记忆实验](list_memory_story_experiment.md)。

### 3.7 固定Top-K长度：多拿或少拿一些源信息

**目的与实现：** 检查接口返回的信息量是否限制效果。使用同一冻结DNN，分别导出/截取K=20、50、100、200，每个K单独训练同结构LIST；Top200前100名与原缓存精确一致。

**最好观察：** Top200在两档的平均RMSE最低：β20为 **0.806405 / 1.055585**，对v1的MAE、RMSE都改善，三个种子的RMSE均改善；β80为0.833955 / 1.089390，RMSE仅低0.000006，MAE略差。Top20／Top50没有带来一致收益。

这轮只做了固定长度对照。原计划的共同变长编码器、根据已见前缀停止/继续、候选集定向查询均未实现，不能写成“主动信息采集已验证有效”。依据：[采集对照](list_acquisition_story_experiment.md)、[实施范围核对](list_implementation_alignment_audit_20260925.md)。

### 3.8 条件高斯：用分布表达跨域迁移的歧义

**目的与实现：** 同一源列表不一定唯一决定目标兴趣，改为学习给定列表的32维潜在用户高斯分布。先比较固定std=0.3与学习对角方差；训练使用同一用户多条目标评分的联合高斯边际似然，预测用条件均值。它与IB不同：这里的高斯是迁移模型，目标函数不是MSE加IB的KL约束。

**默认版本的最好结果：** 学习方差高斯在共同数据β20为 **0.806859 / 1.054166**，比v1平均MAE低0.001638、RMSE低0.001960；固定方差为0.810021 / 1.055355。β80所有新歧义模型都被验证集选回epoch0、λ=0，等于普通均值，差于v1。已完整训练后选回均值，不是漏跑。

**后来做过两轮独立参数探索：**

| 探索 | 候选与目的 | 最好结果及最后保留的决定 |
| --- | --- | --- |
| 评分噪声方差 | 0.25、0.5、1、2、4；调节评分不确定性尺度，潜变量参数保持默认 | 无统一最优。共同数据β20验证选4，测试0.808273 / 1.055347，反而差于默认1；β80选1并退回均值。Book→Movie β80有改善，但仍未超过v1。后续固定1。 |
| 初始潜变量std | 0.1、0.2、0.3、0.5、1；下限0.05、上限2 | 六档中五档改善默认高斯，一档保留0.3；Music→Movie β20选0.5，其余四档选1。它比上下限更值得继续寻优。 |
| std下限 | 0.01、0.03、0.05、0.1；固定上一阶段初始值和上限2 | 验证分数均打平，六档保留0.05；仅一处外层重训测试有极小差异。 |
| std上限 | 0.5、1、2、3；固定前两阶段选择，跳过上限小于初始值的配置 | 五档验证选1；Book→Music β80选2。用户最终决定以后统一下限0.05、上限1，保留初始std寻优。 |

**顺序搜索的最好实际配置，seed2020：** 共同数据β20为 **0.805729 / 1.053277**，β80为 **0.832998 / 1.090821**。前者RMSE优于同种子v1、MAE仍较差；后者两项仍不及v1。三个任务的完整最终结果和参数见第4节。

评分噪声搜索与std顺序搜索是不同实验，不把各自测试最小值拼接起来。评分噪声固定1、std上限固定1是后续策略；不能把历史Book→Music β80上限2的结果重新标为上限1。依据：[歧义建模首轮](list_ambiguity_story_experiment.md)、[噪声方差扫描](list_gaussian_noise_experiment.md)、[std顺序搜索](list_gaussian_sequential_experiment.md)。

### 3.9 条件能量＋朗之万：让潜在兴趣分布更灵活

**目的与实现：** 高斯形状可能过于受限，进一步用有界能量网络修正条件高斯分布，通过带接受/拒绝步骤的朗之万采样（MALA）近似训练及预测。训练使用先验/后验采样；预测只由源列表条件生成潜变量，不读目标测试评分。首轮比较训练和预测都20步、都60步，隐藏宽度64不变。

**默认结构的最好观察：** 共同数据β20，20步版为 **0.808343 / 1.054606**，RMSE优于v1及60步版的1.056190；60步版MAE较低，为0.807658，不能把两版最小指标拼为一个模型。β80两版都选回普通均值。

**后续独立单因素扫描，seed2020：** 训练/预测步长各0.1、0.25、0.5；训练/预测步数各10、20、60；训练链16、32、64；预测链64、128、256；能量上界1、5、10。共享步长拆开后是六组、七条标量轴。每次只改一项，其他项恢复默认；共90个不同配置，默认在各轴复用后展示126行。没有改隐藏宽度、优化器、10轮预算或λ候选。

六档分别在已有15个不同配置中按验证RMSE取最好单项改动。共同数据β20选训练步长0.1，得到 **0.806854 / 1.053862**；β80仍选默认并退回均值。Book→Movie β20选能量上界10，Book→Movie β80选64训练链，Book→Music β20选60预测步，其β80仍退回均值。未运行这些设置的组合。

训练步长和预测步数出现较有价值的局部改善；训练步数、能量上界较敏感，但一些大变化来自变差。预测链数64～256对RMSE的最大绝对影响仅0.000090。扩大网络或延长链并不自动改善推荐。依据：[首轮条件能量](list_ambiguity_story_experiment.md)、[六组敏感性扫描](list_langevin_sensitivity_experiment.md)。

## 5. 目前可以保留的结论

1. **已经有效并吸收到主版本的改动，是DNN源列表与普通物品均值残差。** 额外模块应与这个强版本比较，超过普通均值本身不等于超过v1。
2. **条件高斯的结果最有希望，但优势依赖任务与β。** 它同时具有部分三种子收益和后续单种子改善；仍需区分均值结果、单种子调参结果和MAE/RMSE取舍，不能称为全面最优。
3. **朗之万目前没有稳定胜过更简单的条件高斯。** 它在部分设置有效，但默认及调参结果都有回退均值的情况。现有试验没有证明能量网络学到了多个可解释兴趣峰，也没有证明更多采样步数更好。
4. **细化聚合并没有自动带来收益。** 固定分段、多簇、目标相关加权、物品对记忆都没有形成两档统一改善；这限定的是已实现结构，不能外推成所有细粒度方法无效。
5. **IB和更多Top-K信息只出现局部收益。** 小IB的β20 RMSE改善伴随MAE退步；Top200的β20更好，但需要两倍返回条目，β80几乎不变。二者不能被包装成已经证实的隐私保护、解释性或主动查询能力。

以上是不同独立版本的结果，尚未试验“IB＋记忆＋高斯＋降权”之类组合，本文也不把它们合成为一个已有模型。
