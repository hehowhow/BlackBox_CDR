## 后续模型的数据接口

路径前缀为 `runs/book_movie_protocol_8564/data/`：

| 文件 | 用途 |
| --- | --- |
| train_src.csv | 完整 Books 源域评分；链接到已校验的数据 |
| train_tgt.csv | 排除验证和测试用户后的 Movies 训练评分 |
| train_meta.csv | 仅映射训练用户的目标训练评分 |
| train_users.csv | 22,432 个重叠训练用户 ID |
| validation_users.csv | 7,478 个冷启动验证用户 ID |
| validation.csv | 验证评分，用于选择 epoch、超参数 |
| test_users.csv | 保留历史划分的 7,478 个冷启动测试用户 ID |
| test.csv | 与历史 seed2020 测试文件字节完全相同 |
| id_maps/ | 与原实验一致的原始 ID 到整数 ID 映射 |

评分 CSV 无表头，列为 `uid,iid,y`。用户列表为无表头、每行一个整数 ID。
86,572 名目标域非重叠训练用户仍参与目标侧训练；60/20/20 仅描述重叠用户。

**原 experiment.py/Run 只支持二路划分，不可直接套用。** 它根据“全部重叠用户减
测试用户”生成映射训练用户，会把验证用户错误纳入训练。后续模型需要明确读取
本协议的三份用户列表，并为冷启动验证提供独立评估入口。当前目录使用不同布局，
避免旧入口静默加载成二路划分。

Book/Movie 原始物品 ID 无交集。数据协议是随机用户留出，允许获取冷用户的
源域历史；它没有时间切分约束，完整目录编码也不是严格的未知目录归纳设置。
历史测试集此前已经评估，本协议仅冻结后续使用方式，不宣称建立了新的盲测集。

## 选择和测试约束

- 固定目标训练数据量，模型不能把验证用户的评分加入预训练或映射训练。
- 基线的统计量只来自 train_tgt；拟合和验证进程禁止打开测试标签文件。
- 候选基线列表与平滑参数在运行前固定；按验证 MAE/RMSE 分别选出设置。
- selection.json 先保存选择、模型统计量哈希和协议哈希，测试阶段再加载检查。
- 测试入口创建独占执行标记，避免意外反复测试；预先指定的候选统一评估一次。
- 本轮不把验证数据加入最终拟合；后续跨域模型比较也应使用相同目标训练集。
- 以后若修改数据或运行配置，另存新的协议版本，不能覆盖 8564 的产物。

逐样本预测位于 `results/test_predictions.npz`；详细指标（含每用户等权 MAE）
位于 `results/summary.json`。测试文件只用于最终评价，不用于后续超参数选择。
