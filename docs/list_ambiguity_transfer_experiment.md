# 条件跨域建模：Book→Movie 与 Book→Music 扩展

本轮将Music→Movie实验中两个指定版本——**条件高斯：学习方差**、**条件能量：20步朗之万**——扩展到当前论文任务中的另外两个方向。

## 比较内容

| 版本 | 用途 | 实现来源 |
|---|---|---|
| 原版LIST（残差v1） | 用户要求的主对照，两个新任务重新训练 | 原封不动调用`small_task_comparison.list_run` |
| LIST成组训练对照 | 保留上轮的训练组织对照 | 原封不动调用8913的`point_matched` |
| 条件高斯：学习方差 | 指定扩展版本 | 原封不动调用8913的`gaussian_learned` |
| 条件能量：20步朗之万 | 指定扩展版本 | 原封不动调用8913的`energy_20` |
| 普通物品均值 | 提供评分基准 | 当前阶段的目标训练评分统计，无平滑 |

这里的原版是GitHub归档的“普通均值+列表残差”LIST。之前8638在两个方向的结果属于更早的“全局均值+可学习物品偏置”LIST，不能直接作为本轮主对照，所以重新运行归档代码。

## 固定设置

- 任务：Book→Movie（37,388名重叠用户）、Book→Music（16,738名重叠用户）。
- 复用8638的已核验数据、内外层用户划分和源DNN Top100；源/目标原始物品ID交集为0。
- β=20%/80%；三个模型种子2020/2021/2022。每个任务、β和种子的所有方法使用同一份源列表。
- 保留原排名加权聚合、32维源/目标向量、32→64→32编码器、dropout0.1、固定普通物品均值、目标内积和全局λ。
- 10轮，Adam lr=0.001、weight decay=1e-5。验证集在epoch0..10和λ={0,.25,.5,.75,1}上选择，重新初始化后在完整外层训练集重训所选轮次。
- 高斯初始std=0.3，学习范围0.05..2；联合目标评分边际似然训练。
- 能量为条件高斯参考分布上的有界MLP修正；沿用MALA步长0.25、训练32条链、推断128条链、训练与推断20步。
- 概率版本和成组对照为每批64名完整训练用户；原版保持2048条交互一批。同样10轮不保证更新次数相同，因此报告同时保留成组对照，不把训练组织差异归因于概率建模。
- 冷用户推断只根据源列表生成表示；真实目标训练评分只进入训练后验，测试评分不得进入采样器。

两数据集×两β×三种子×四个训练版本，共48组内层选模及外层重训。全部最终模型及预测冻结后统一读取测试评分。结果报告MAE、RMSE、三种子标准差，以及相对新跑原版和成组对照的差值。没有在这两个任务新增模型结构或重新搜索超参数。

### 直接结论

1. **Book→Movie、β20出现了可重复的小幅改善。** 两个版本在三个种子的MAE和RMSE上都分别低于原版。平均RMSE降低约0.002855，相对降幅约0.275%；平均MAE降低约0.0051至0.0053。两版本的RMSE只相差约0.00000086，不能据此认定朗之万优于高斯。
2. **Book→Movie、β80变差。** 高斯和朗之万在三个种子的两项指标上均高于原版；相对原版的平均RMSE分别增加0.008582和0.006966。它们也高于同成组训练的确定性对照，因此这一档的退化不能完全用原版与成组批次不同来解释。
3. **Book→Music、β20接近原版，但平均指标略差。** 两个概率版本都超过成组确定性对照，但没有超过按原始训练方式运行的归档LIST。逐种子RMSE为两个更低、一个更高；平均RMSE差距为+0.000241和+0.000380。
4. **Book→Music、β80基本退回均值附近。** 两个版本均有两个种子选择epoch0、λ=0，另一个选择epoch2、λ=0.25。原版仍略好，尤其是MAE；没有得到概率模型的增量收益。

这些是固定划分、三个模型种子下的数值比较，没有新增显著性检验。新数据上的四档设置只有Book→Movie β20在两项均值指标上超过原版；不能表述为跨数据集、跨监督规模的一致提升。
