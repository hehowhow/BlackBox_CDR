# LIST 首轮原型与固定K对照实验

2026-09-24。本轮按用户要求直接比较改动后的 MAE/RMSE，不将覆盖诊断或机制分析作为开跑前置条件。三个 agent 分别负责 IB、列表深度和组合记忆；它们是三个独立模型方向，没有串成一个复杂模型。

2026-09-25范围更正：48个实际模型全部完成，指标复核为PASS，两个Slurm作业正常结束；但原优化方案没有全部实现。尤其信息采集只完成固定K对照，R2a停止/继续策略和R2b候选查询都未实现。IB是隐藏层VIB变体，组合记忆是小型原型，二者也缺部分文档对照。详见 [实施核对](list_implementation_alignment_audit_20260925.md)。

## 共同参照与协议

“原版 LIST”指已经上传 GitHub 的全局排名池化＋普通物品均值残差版本，冻结结果来自 `runs/small_task_comparison_8650` 的 `residual_real`。该运行中的 `LIST_original` 行是更早的非残差模型，不能混作本轮的原版。

| 设置 | 本轮取值 |
| --- | --- |
| 任务 | Music→Movie，源侧去除跨域重复物品，17,904 名重叠用户 |
| 冷用户测试比例 β | 20%、80% |
| 模型种子 | 2020、2021、2022；三次训练的指标均值，不是预测集成 |
| 源服务 | 同一冻结 DNN；学生只见返回的 ID 和排名 |
| 基底 | 当前训练评分的普通物品均值，不平滑；未见目标物品用训练全局均值 |
| 学生 | 原源/目标维度32，MLP 32→64→32，全局排名权重池化 |
| 优化器 | Adam，学习率0.001，weight decay 1e-5，batch 2048，原 dropout 0.1 |
| 选模 | 10轮内层训练；冷用户验证 RMSE 选择 epoch 0–10 与 λ∈{0,0.25,0.5,0.75,1} |
| 重训 | 按验证选择从原初始化在完整外层训练集重训，不接着内层模型训练 |
| 评价 | 每条线的候选全部冻结后才读取测试标签；统一汇总另做 CPU 独立复算 |

数据划分、原有模型、参数文件和预测文件均保留；本轮写入新目录。历史测试集已经用于多轮探索，本轮仍属于探索实验。

## 各线实际修改

| 路线 | 固定候选 | 修改的内容 | 保留的内容 |
| --- | --- | --- | --- |
| IB | η=0、1e-4、1e-3 | 在隐藏表示加入高斯采样及 KL 约束，推断使用均值 | Top100、原全局池化、目标内积、普通均值基底 |
| R2前置对照，核心策略未实现 | K=20、50、200；K100为冻结参照 | 改变返回列表长度，每K单独训练；Top200由同一冻结源模型新导出 | 原聚合器和评分头 |
| Engram 启发的记忆 | 前20/前50名物品对 | 训练用户中至少3人支持的无序物品对，最多8192项×32维；查表均值与原池化向量相加 | Top100接口、单个原编码器及评分头 |

IB 的 η=0 是相同随机结构的对照，不等于确定性的原版 LIST。瓶颈置于零初始化输出层之前，训练采样的起点仍严格为普通均值。KL 按64个维度求和，再按训练交互平均；无源列表的交互不产生 KL。

采集线先回答“更短或更长的列表是否改变效果”，本轮不实现主动停止策略，也不把固定截断称作主动采集。K20/K50分别返回原版的20%/50%条目，K200返回两倍条目。Top200需要源服务支持更长返回；不能把它的收益全部归给学生模型架构。原缓存的 Top100 前缀、共享参数初始化会核对。

记忆线只用当前阶段训练用户建表；内层选择用 inner_train，完整重训用 outer_train。验证/测试用户不参与计数或建表，未命中组合返回零。它是 Engram 思想启发的组合查表实验，没有复现完整 Engram，也不预设它能加速。

## 从结果可以直接得到什么

**本轮没有任何一个改动，在两档比例的 MAE 和 RMSE 上都超过原版 LIST。** 全部新版本仍超过普通均值，但这不能替代与原版 LIST 的对照。

**信息采集线的 Top200 最值得保留为下一轮候选。** β20 的 MAE 平均降低0.002092，RMSE降低0.000541（约0.051%）；三个种子的RMSE都改善。不过MAE均值改善主要来自seed2022，且β80的RMSE只降约0.000006、三个种子的MAE都略差。因此这是有范围限制的小收益，不能说已经全面胜出。它需要返回两倍条目；本轮尚未实现主动查询策略。

**IB 小约束只改善了一个局部指标。** η=1e-4在β20的三个种子上均降低RMSE，平均降低0.000500（约0.047%），但平均MAE变差；β80的三个种子RMSE都变差。η=1e-3在两档都明显变差。η=0的采样对照也没有一致提升。这里不能据此宣称IB提升了解释性或稳健性；较强η与β80的多个选择达到10轮上限，结论仅限当前相同训练预算与已测参数。

**组合记忆没有表现出一致收益。** Top20组合记忆在β80的平均RMSE降低0.000168，但只有一个种子改善，β20三个种子均变差。Top50组合记忆也没有稳定替换原版的依据。该结果针对本轮的无序物品对查表，不代表完整Engram在其他任务上无效。

上述结果只支持具体已测变体的比较，不能据此认为原文档三条方案均已验证。尚未完成的R2应按原方案补齐：共同变长编码器、基于已见前缀的停止/继续策略，以及相同平均预算的随机分配对照。Top100与Top200保留为固定K参照，不用继续扫描K代替实现原定策略。
