这些负结果限定于已测试的数据方向、划分、表示与训练预算，不是所有细粒度方法均无效的证明。逐条非线性交互、集合自注意力与已运行实现并不完全相同，但当前缺乏足以重新启动这类结构试错的新证据。证据选择、二阶聚合、邻居检索和排名辅助损失也不列入当前实验队列；文献背景保留，不作为隐含的必跑任务。

**共同起点仍是已经归档的全局 LIST。**

\[
h_u=\sum_{r=1}^{100}a_r e(s_r),\quad
a_r=\frac{1/\log_2(r+1)}{\sum_t1/\log_2(t+1)},
\]
\[
z_u=\mathrm{MLP}(h_u),\qquad
\hat y_{ui}=\mu_i^{\mathrm{train}}+\lambda z_u^\top v_i.
\]

源服务为冻结 DNN；学生仅读取物品 ID 和排名。学生源/目标表示维度32，MLP为32→64→32。基底为普通训练物品均值，不平滑；无源列表时修正为零，训练未见目标物品使用训练全局均值。当前选模用冷用户验证 RMSE 联合选择 epoch 和 λ，最终从原初始化重训。详细参数和结果见 [主版本快照](current_list_version.md) 与 [配置记录](../configs/list_residual_v1.json)。

以下每条路线只改变必要部分，不将更换基底、源骨干和多个新模块混入同一比较。

**R1：用 IB 研究有限监督下的泛化。**

拟议叙事是：源列表有预测价值，但重叠用户监督有限；学生可能把训练用户特有的细节记入表示。约束表示容量，能否保留可迁移信号并改善新用户预测？“存在过拟合”及“IB能缓解它”都应由训练/验证曲线与对照支持，不能预设。

最小工作流：

原 Top100 → 原排名加权全局池化 → 随机瓶颈编码器 → 原目标物品内积 → 普通均值修正。

编码器只接收原全局池化向量 h，不让目标物品提前参与条目编码；不加入注意力、硬选择、聚类或记忆。用两个输出表示高斯均值和方差，训练时采样，推理时固定采用均值。目标可写为：

\[
q_\phi(z|h_u)=\mathcal N(m_\phi(h_u),\operatorname{diag}\sigma_\phi^2(h_u)),
\]
\[
\mathcal L=
\mathbb E_{z\sim q_\phi}[(y_{ui}-\mu_i^{\mathrm{train}}-z^\top v_i)^2]
+\eta\,\mathbb E_u D_{\mathrm{KL}}(q_\phi(z|h_u)\|\mathcal N(0,I)).
\]

η是信息约束强度，与冷用户比例β不同。训练修正强度为1，最终λ仍通过相同验证规则选择。应在实现前固定 KL 的按维度/按用户归约方式；若评分项按交互采样，要写明 KL 是用户均匀加权还是按用户交互频次加权，避免隐含地改变正则强度。

| 必要对照 | 要排除的解释 |
| --- | --- |
| 当前确定性 LIST | 是否真正改善原主版本 |
| 同一随机编码器，η=0 | 改善是否只来自采样噪声或增加的输出参数 |
| 同一随机编码器，η>0 | KL约束是否有独立收益 |
| 调整普通 dropout/weight decay 的 LIST | 普通正则是否已经足够 |

核心指标仍为 RMSE，附带 MAE。围绕这条叙事增加监督规模曲线、受控列表扰动曲线、KL代理量与误差的关系；这些是该路线的机制验证，不另算新模型模块。真实与错配列表分别重训的对照用于判断是否仍有用户对应的源信息增量。

继续条件：相对无KL和普通正则对照，在新用户验证及重复训练中有稳定收益，或者在明确的少监督/扰动条件下表现出可复现优势。停止或降级条件：优势只来自普通正则、λ趋零而完全回退均值、或只有历史测试偶然改善。若仅改善稳健性而未提高干净数据精度，应据实描述为相应取舍。

IB不自动提供可解释性或识别热门噪声；在池化之后施加IB也无法恢复池化已经丢失的条目信息。实现时还必须处理随机初始化：高斯均值为零不等于每次采样的修正为零，不能直接声称原“零修正起点”已无缝保留。该问题需在具体原型中明确实现并核验，不在文档阶段假定解决。

相关原始工作：[Deep VIB，ICLR 2017](https://arxiv.org/abs/1612.00410)、[CDRIB，ICDE 2022](https://github.com/cjx96/CDRIB)、[CoTrans，CIKM 2024](https://arxiv.org/abs/2409.19574)。IB用于CDR已有先例；单纯加入KL不构成充分创新，差异需落在受限列表接口的问题及机制证据上。

**R2：把信息采集作为独立问题，先选择一种接口设定。**

拟议叙事是：同一份固定Top100未必给所有用户提供足够或必要的跨域证据。在预算约束下，能否把查询资源用于更有价值的观测？已有结果尚未证明当前观测不足，因此首先需要诊断，而不是先把复杂查询策略写成必要模块。

本地导出代码在冻结模型上对全目录打分后取TopK，见 [导出实现](../scripts/list_source_backbones.py)。相同用户、模型及候选集的确定性重复请求不产生新信息。缓存删项、重排、分段属于信息加工；静态排序中连续排除已返回头部相当于分页。当前源列表未过滤历史，不能把返回条目称为未消费物品。

R2有两个替代原型，先选其中一个，不把二者串联。

| 原型 | 研究对象 | 当前材料能支持什么 | 新增接口假设 |
| --- | --- | --- | --- |
| R2a：按需深度 | 哪些用户需要更长列表？ | 用现有Top100模拟20/50/100的可见前缀 | 真正节省传输需要可变K或分页 |
| R2b：候选集合查询 | 哪些额外比较最有助于目标预测？ | 冻结DNN可作为新服务协议的模拟器 | 源服务允许对指定候选集合返回子集排名 |

R2a的最小流程：先读20条 → 判断停止或继续到50条 → 必要时继续到100条。LIST使用共同的变长编码器；唯一新增机制是停止/继续策略。只用训练用户目标监督估计下一页的预期预测收益，验证确定策略，测试冷用户不提供目标反馈。策略决定继续前不能读取隐藏后缀及其衍生表示。

对照为固定K、相同平均预算的随机K分配、学习分配。编码器在训练时见到多种前缀，控制截断带来的分布变化；原固定Top100主版本另作冻结参照。评价RMSE/MAE对平均返回条目数和调用次数的曲线。缓存模拟不能直接宣称线上延迟下降；若获取Top50会重传前20条，重复传输也计成本。

R2a的继续条件是在相同预算下误差更低，或同等质量下有可靠成本下降。若固定短前缀已经达到相同效果，就保留简单截断结论，不强行添加动态策略。

R2b提供：
\[
\operatorname{Rank}(u,C)\longrightarrow C\text{内的Top-}m\text{ ID及排序}.
\]

它观察此前全目录头部没有展示的取舍。查询仍只获得教师判断，不是新增真人反馈。学生候选ID必须来自合法公开目录或训练期已返回ID；没有公开目录时，不允许通过本地教师文件把完整物品表偷偷提供给学生。教师可以用自身模型响应，学生不读教师分数或向量。

最小比较是随机候选、覆盖性候选、目标任务导向候选，三者共享同一查询协议、编码器与评分器，匹配查询预算。策略在训练用户上学习，测试时只按可见响应行动。优先每用户共享一组查询结果；如按每个目标物品分别查询，预算必须按用户×物品计入。

候选集第一名不是全目录第一名，需保留候选上下文或采用同集合内成对比较表示，不能直接拼接后套原全局排名权重。原LIST单列为原接口参照，不能将扩展接口收益全部归因于查询策略。

R2b的继续条件是在相同协议和预算下优于随机/覆盖性查询，并在独立划分上重现。若收益只是因为返回更多条目，应归于额外信息量；若简单更深TopK同样有效，不能称主动策略具有独立贡献。

预算至少记录：
\[
B_{\mathrm{calls}},\qquad
B_{\mathrm{return}}=\sum_q|\mathrm{return}_q|,\qquad
B_{\mathrm{candidate}}=\sum_q|C_q|.
\]
另报独特ID数、请求/响应字节数和实际用时。重复ID占传输成本；候选规模只是源端工作量代理，不是精确FLOPs。不得仅比较每次K相同而忽略调用次数。

相关启发：[主动特征采集，ICML 2024](https://proceedings.mlr.press/v235/valancius24a.html)、[主动子集排序，AISTATS 2019](https://proceedings.mlr.press/v89/saha19a.html)。这些工作支持问题建模，概率排序等理论条件不能自动移植到确定性DNN；“主动采集”本身不是新概念。

**R3：Engram只保留为有准入条件的组合记忆候选。**

拟议叙事是：如果一些源列表组合在不同用户中反复出现，并携带目标评分增量，专门记忆这些模式是否比普通共享网络更有效？该路线仍在原列表信息内工作，不能宣称获得了新观测。

当前阶段仅建议设计训练侧组合支持度与验证覆盖诊断，不直接进入记忆模型训练。可先研究前20名的无序物品对，每用户最多190对；这是一个拟议范围，不是已经冻结的最终实验参数。推荐排名不是消费顺序，不能直接把相邻名次当成语言n-gram或真实行为转移。

统计与建表只用当前训练用户；验证列表只作覆盖检查，不更新表，测试数据不参与选择。进入模型阶段前应看到跨不同训练用户的重复支持及对验证用户的可用覆盖；单纯热门组合命中多，不能证明有目标预测价值。支持度阈值和覆盖判据应在诊断实施前说明，不根据测试效果反复修改。

若准入诊断支持，再建立小型组合字典，把组合表示与原单物品全局表示送入一个编码器，保留一个评分修正头。初版不同时加入IB、目标注意力、检索或复杂多哈希系统。哈希扩容是后续实现选择，不是必须的研究模块。

启动后才需要的针对性对照：同参数量扩大MLP、FM/NFM式组合表示、显式组合记忆，以及必要的错配列表对照。它们用于检验独立贡献，不意味着当前新增多条并行研究任务。

继续条件是覆盖可用，且专门记忆相对普通组合模型/同容量模型具有稳定质量或成本优势。低覆盖、收益仅由更大参数量解释，或只在少量热门组合上拟合改善时，停止或降级，不靠持续扩表维持路线。

Engram不保证小LIST更快，组合枚举也不是常数成本。参考 [Engram](https://arxiv.org/abs/2601.07372)、[NFM](https://arxiv.org/abs/1708.05027)。[ComeIR，2026年预印本](https://arxiv.org/abs/2605.11447)已经在生成式推荐使用Engram，因此不主张首次将Engram用于推荐。

**共同的实施与评价边界。**

| 项目 | 后续实验要求 |
| --- | --- |
| 主版本 | 保留归档模型作为固定参照，不覆盖旧运行 |
| 数据 | 同一去重版本；内层训练、验证和外层测试按用户隔离 |
| 信息访问 | R1/R3仅用原ID/排名；R2新增能力单独声明 |
| 基底 | 各阶段仅由该阶段训练评分计算普通物品均值 |
| 选模 | 以验证RMSE为主，附带MAE；统一或匹配调参预算 |
| 参数 | η、组合支持阈值、采集成本和策略候选等在训练前明确；本文不是可直接执行的冻结协议 |
| 初始化 | 比较共享参数与随机种子；新增随机模块的初始预测需单独核验 |
| 模型选择 | 验证选择后从原初始化在外层训练数据重训；测试标签不指导训练、查询或选择 |
| 确认 | 方向确定后用新划分、其他跨域方向确认；当前历史测试已多次用于探索 |
| 资源 | 如后续启动GPU实验，继续使用两卡Slurm；本次未提交作业 |

当前建议顺序为：先设计R1最小原型；R2独立界定一种协议并做信息量/成本诊断；R3先过组合支持与覆盖门槛。三者不互相作为前置条件，K前缀曲线和组合统计也不是IB实验的必做前置任务。目标用户标量偏移等历史诊断可作为解释既有收益的背景，但不在本轮自动追加为必跑实验。

这些路线分别检验“是否没有学稳”“是否需要不同观测”“是否存在可复用组合”，尚不能断言其中哪一个是当前瓶颈。细粒度聚合方向保持暂停，除非后续出现独立的新证据支持重新考虑。
