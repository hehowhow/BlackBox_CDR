\par\medskip\par\medskip\footnotesize
\noindent\textbf{Protocol.} $\beta$ is the fraction of overlapping users held out as target cold-start test users. We retain all target-only users in training. Music-to-Movie removes cross-domain duplicate items from the source and contains 17,904 overlapping users (the original paper has 18,031). The other tasks contain 37,388 and 16,738 overlapping users.
\par\smallskip\noindent\textbf{Backbone and training.} TGTOnly, EMCDR and PFCDR use the official 10-dimensional MF. All LIST variants receive the same newly trained MF Top-100 IDs/ranks; their established 32-dimensional list/target representations are retained. Source and target MF train for 10 epochs using Adam (0.01). Source/target batches are 512 for Book tasks and 256 for Music-to-Movie. EMCDR uses mapping batch 128 and learning rate 0.01. PFCDR uses full-catalog inversion (300 iterations, batch 200), mapping learning rate 0.005, mapping batch 512/512/1024, and the released MF implementation's 70,000-user voting rule.
\par\smallskip\noindent\textbf{LIST variants.} LIST V1 uses 2,048 interaction batches; LIST V1 + Langevin and LAPT use 64 complete-user batches. Both Langevin variants retain the same fixed sampling settings. LAPT adds the current rank-aware shared-pattern reconstruction and residual attention with masked-ID supervision. No SID/coarse codes or additional hyperparameter search are used.
\par\smallskip\noindent\textbf{Evaluation.} Epochs (and LIST correction weights) are selected on an independent inner validation split, then models are freshly refit on all outer training users. All 54 prediction arrays are frozen before test-label evaluation. This differs from the released code's best-test-epoch reporting. Results are for one seed, not the paper's ten-run averages. Bold identifies the best unrounded value within each row. No statistical-significance claim is made.
\par\smallskip\noindent\textbf{Mean fallback.} Validation selects $\lambda=0$ in 3 of nine LAPT settings and 2 of nine LIST V1 + Langevin settings; these predictions equal ordinary training-item means. LIST V1 selects nonzero corrections in all nine settings.
