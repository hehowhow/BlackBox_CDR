# LIST：跨域迁移歧义的条件生成建模实验

日期：2026-09-26。任务是比较这一条故事线的模型改动对推荐评分误差的影响，不增加机制实验或停止阈值。实验已完成，设计、实现和结果均记录在本文。

## 研究问题与改动边界

给定一份有限、没有源评分的 Top100 列表，目标用户偏好未必能够唯一确定。我们尝试学习给定源列表的目标用户表示分布，再用该分布的均值预测目标评分。

沿用已归档 LIST 的源 DNN、同一批 Top100 ID/rank、学生源物品查表、固定排名加权池化、32维表示、目标物品内积、训练数据普通物品均值和全局验证选择的 λ。改变的是池化之后的跨域映射及其学习目标。没有引入 IB、SID、聚类、多兴趣分段、注意力、额外门控、列表补全或源端新信息。

参考：Pang 等，NeurIPS 2020，[Learning Latent Space Energy-Based Prior Model](https://papers.nips.cc/paper_files/paper/2020/hash/fa3060edb66e6ff4507886f9912e1ab9-Abstract.html)。本实验是列表条件下评分建模的改编，不是原论文复现，也不保证生成式建模会提高点预测。

## 数据与共同协议

- Music→Movie 去重版；删除源域与目标域共享原始物品后有17,904名重叠用户，目标评分保持原样。
- β=20%和80%为测试冷用户占重叠用户的比例。沿用 `small_task_comparison_8650` 的内外层用户划分。
- 三个模型种子：2020、2021、2022；每个种子复用原版对应的源 DNN Top100。
- embedding=32，hidden=64，dropout=0.1；Adam lr=0.001，weight decay=1e-5；10轮上限。
- 验证集在 epoch=0..10 与 λ∈{0,0.25,0.5,0.75,1} 中按 RMSE 选模；从相同初始化在完整外层训练集重训所选轮次。训练 λ=1。
- 普通均值只由对应阶段的目标训练评分计算，不平滑；无源列表或未见目标物品的残差为0。
- 所有30个新模型及预测冻结后，再统一读取测试评分；训练进程禁止读取测试标签、源历史、源模型权重和分数。

概率模型的一次潜变量对应同一用户的全部已观测目标训练评分，因此新版本以64名用户为一批，保留每人的全部评分，按该批评分总数归一化联合损失。dropout在每个用户的条件编码处采样一次。目标域独有用户参与物品均值，其残差恒0，对概率模型没有可训练的评分梯度，故在新版本的成组更新中省略。原版是按2048条交互训练；这个训练组织差异单独设置确定性 LIST 对照，不能计作生成模型本身的收益。

| 原版 LIST | 引用已归档8650结果 | μ_i+λ MLP(h_u)ᵀv_i |
| 成组训练 LIST | 原确定向量和MSE；采用新版本共同的用户成组批次 | 原确定向量 |
| 条件高斯：固定方差 | z\|h服从以原MLP为均值、std=0.3的32维高斯；联合边际似然训练 | 精确高斯均值 |
| 条件高斯：学习方差 | 条件方差由隐藏层预测；std限制在0.05..2 | 精确高斯均值 |

## 目标函数与采样对应关系

原池化得到 h，原 MLP 输出 m(h)。高斯版本学习：

\[
z_u\mid h_u\sim\mathcal N(m(h_u),D(h_u)),\quad
r_{ui}\mid z_u\sim\mathcal N(\mu_i+z_u^\top v_i,1).
\]

观测噪声方差固定为1。对每个训练用户的全部已观测评分联合积分消去z，以精确边际似然训练；未观测评分不填零，不作为负例。计算在32维空间用矩阵恒等式完成。训练目标不是随机表示的MSE加KL。

能量版本为：

\[
p_\theta(z\mid h)\propto\mathcal N(z;m(h),D(h))\exp[-e_\theta(z,h)].
\]

e使用输入[z,h]、隐藏64维的Tanh MLP，再以5 tanh(raw/5)限制能量修正。高斯参考保证分布可归一化。能量输出层零初始化，所有新版本共享原版参数的精确初始化；方差头零权重、初始std=0.3。

训练采样两种分布：

1. 只根据源列表的条件先验 p(z|h)。
2. 根据源列表及该用户目标**训练**评分的后验 p(z|h,R_train)。

利用 E_post[∇E+∇评分负对数似然]−E_prior[∇E] 估计联合最大似然梯度。采样轨迹停止梯度；优化器更新条件均值、方差、能量网络、源/目标物品表示。日志中的 `objective_surrogate` 是构造正确梯度的随机代理量，不是已求归一化常数的边际NLL。

采样采用带Metropolis校正的朗之万（MALA），在高斯参考的白化坐标中步长0.25。后验链的高斯部分来自当前用户已观测目标训练评分的解析高斯后验；非高斯能量由MCMC处理。这个预条件方式只服务数值采样，没有增加模型组件。

训练32条链，推断128条链；20/60步为两档固定设置。使用成对正负高斯初值/噪声以及训练先验、后验公共随机数降低采样误差，不改变单链的目标分布。Metropolis校正处理离散步长偏差，有限长度仍不保证充分混合。

预测只输入源列表，通过条件先验得到候选用户向量，然后：

\[
\hat r_{ui}=\mu_i+\lambda\left(\frac1M\sum_m z_u^{(m)}\right)^\top v_i.
\]

预测采样器没有目标真实评分参数。不生成假历史或伪评分作为新增训练数据，不使用用户级可靠性门控。能量版没有在原版输出上单纯添加零均值噪声，而是通过目标训练评分学习条件分布。

### 可以直接从结果看到什么

1. **β20下，学习方差的条件高斯最好。** 相对归档原版，平均MAE降低0.001638、RMSE降低0.001960，RMSE相对降幅约0.186%。三个种子的RMSE分别都更低；MAE是两个种子更低、一个更高。它也在两项指标上超过本轮同批次的确定性对照。
2. **20步朗之万有小幅收益，但没有超过更简单的学习方差高斯。** 相对归档原版，平均RMSE降低0.001520，MAE只降低0.000153。三个种子中两个RMSE更低、一个更高。相比学习方差高斯，它的平均MAE高0.001484、RMSE高0.000440。
3. **60步没有进一步改善RMSE。** 相比20步，平均MAE降低0.000685，但RMSE升高0.001584。该版本相对归档原版的RMSE差值为+0.000065，基本持平、略差。
4. **β80下，五个新版本的三个种子全部选择了epoch0、λ=0。** 因而最终预测都严格等于普通物品均值。这不是指标复制错误，也不是没有运行训练：各候选都完成了10轮验证选择，只是在验证集上没有选择非零修正，按事先规则外层重训0轮。

本轮数值支持“条件概率建模在β20出现了小幅评分收益”，还不支持“朗之万比简单高斯更好”或“在两档监督规模下都优于原版”。没有进行显著性检验；三个种子和复用历史划分不足以把小幅提升描述成普遍或显著改进。

### 比较时需要保留的训练差异

本轮为联合建模同一用户的目标评分，采用64用户一批；归档原版为2048条交互一批。除了dropout的共享粒度不同，**同样10轮不代表相同优化器更新次数**：内层训练每轮，β20为本轮180次、原版730次，β80为本轮45次、原版600次。目标域独有用户在本轮仍参与均值，但不产生额外成组更新。

因此成组确定性对照很必要。它本身在β80也回退到均值，不能把该档退化单独归因于条件高斯或能量建模；训练组织和更新次数也是此次比较的限制。这里没有增加额外实验来解释退化原因，以上只是对实际执行参数的如实说明。
