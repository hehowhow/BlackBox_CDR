Book→Music为9,995,633条，Book→Movie为10,595,574条。
若按重叠用户数，则Book→Music最小；本轮按完整训练规模选择Music→Movie。

沿用8638的去重版本（从源Music删除2,441个共享物品、34,881条评分；目标Movie不变）。
共2,760,244条源目标评分、17,904名重叠用户。仅比较β=20%与80%，每档三个种子2020/2021/2022。
数据、内层验证与外层测试用户、现有LIST预测都不重新划分或修改。

| 方法 | 源端 | 目标端或迁移方式 |
| --- | --- | --- |
| 普通物品均值 | 无 | 同一最终训练集的物品真实评分均值，不平滑 |
| 原LIST | 既有DNN源Top100 | 原LIST内积，复用8638冻结预测 |
| 优化LIST | 同一DNN源Top100 | 固定普通均值＋列表修正，验证选择修正强度 |
| 优化LIST打乱对照 | 同一列表，错配用户 | 同结构、同初始化、同批次种子，完整重新训练 |
| EMCDR-MF / DNN | 对应骨干内部有效用户向量 | 作者无偏置用户向量映射 |
| PFCDR-MF / DNN | 对应骨干内部信息 | 作者条件反演、原型映射、目标用户投票 |

DNN基线与LIST共享同一源模型权重。MF/DNN同骨干的EMCDR与PFCDR共享源目标预训练权重。
比较MF主表版本并加入DNN补充版本，避免只用一个较弱骨干作为对照。
所有模型对训练未见目标物品都回退普通均值。

优化LIST保留原维度32、hidden64、dropout0.1、rank池化、内积目标头、Adam0.001、weight_decay1e-5、batch2048。
固定物品均值，不再学习物品偏置；编码器最后一层零初始化，使初始输出等于均值。
修正训练使用lambda=1，在内层验证上联合选择epoch0..10及lambda=0/0.25/0.5/0.75/1。
不另外搜索残差惩罚，不修改K，不扩展网络。lambda=0可以退回纯均值，但不保证测试成绩不劣于均值。
无源列表用户修正为零。学生只接收ID/排名，不读取源模型、评分或返回分数。
真实/打乱对照在inner_train、validation、test三个用户组内分别固定错配，再独立训练。

每个方法先用相同内层冷用户验证选择轮数，再从相同初始参数重新训练全部外层训练评分。
优化LIST的lambda在重训前冻结。EMCDR/PFCDR最终目标预训练也重新初始化，仅使用完整外层训练评分。
测试用户始终不进入目标训练，验证用户只在最终重训时加回。

骨干维度10、源目标预训练各10轮、Adam0.01、weight_decay0；源batch512，目标batch256。
源512是为了保持既有DNN源模型一致，与作者task3的源batch256不同，不声称逐参数复现。
EMCDR映射Adam0.01、batch128、最多10轮。PFCDR反演300步、batch200、Adam1e-4、weight_decay1e-4、目标评分5及原warmup/cosine调度；
原型映射Adam0.005、batch1024、最多10轮；公开代码实际K70000不变，候选包含全部目标用户行。
不搜索骨干学习率或投票K，因此比较的是这些预先指定的公开设置，不是调参后的性能上限。

核验包括作者原生评分/反演梯度/投票、优化LIST零修正与梯度可学习性、无列表用户回退、
冻结源权重不变、checkpoint恢复预测、真实/打乱初始参数相同、独立groupby物品均值、代码和数据哈希。
全部新模型冻结后才统一读取测试标签。报告三种子均值、样本标准差与配对用户簇置信区间。
